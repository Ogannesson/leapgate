# 新界面冒烟清单

这份清单验证新界面（`leapgate-client` 的 `leapgate_ui/`）的构建：便携目录、便携包和安装版。第一版写于 M2a 验收（2026-10-31），之后每个里程碑往后追加（`03-实施方案.md` §8.5）；M4~M7a 当时没有追加，2026-11-06 切换（M8）前补齐。切换前全过一遍；切换后每次合并上游跑一遍。每条写了怎么做和怎样算通过；没通过的记下现象、日志位置和截图。

M8 起发布的 `leapgate.exe` 就是新界面，构建脚本默认编新界面。旧界面便携版只保留到第三轮（M9）做完，用来测新界面还没有的 TCP 隧道、终端、摄像头，以及第 8 节的五项。

分两层：
- **引擎和安装层**沿用 `docs/第二期客户端冒烟清单.md`，只引用、不抄：§4 安装、§5 外呼、§6 与原版共存、§9 卸载，以及 §7 每条的判定条件。新界面没有安装页，安装由主页的"安装"提示卡发起，这几节的入口和差异写在第 21 节。
- **界面层**是下面各节，按新界面的操作步骤重写。

## 准备

- 两台 Windows 10 或 11 x64 机器：控制端 A、被控端 B 都跑新界面便携版（各节另有说明的除外）。都指向同一个 leapgate-server，下文写作"你的服务器"。
- **同一台机器上新旧界面不同时运行**：两者共用主 IPC 管道，同时运行时后启动的那个连不上（`03-实施方案.md` §7.1）。要用旧界面便携版时，先退出新界面；装着新界面安装版时，先停掉它的服务（`sc stop Leapgate`）并退出托盘，用完再启动服务（`11-M8拆法.md` M8-8）。反过来，装着旧界面时也先退出它，连托盘和服务一起停。
- 被控端设一个固定密码；控制端的配置里填好服务器和 Key。
- 新界面的日志在 `%APPDATA%\Leapgate\log\`（文件名 `leapgate_r*.log`）。每启动一次辅助进程（第二个实例、`--connect`），`leapgate_rCURRENT.log` 都会换新，常驻进程接着写改名后的文件，所以要看全部日志文件。界面层的事件在日志里以 `leapgate ui:` 开头。
- 无人值守跑的辅助脚本在 `scripts/e2e/`：`leapgate-e2e.ps1`（起停、改配置、发起连接、关会话、读日志）、`leapgate-post-input.ps1`（向窗口投递鼠标和按键消息，不占用真实鼠标键盘）、`leapgate-uia.ps1`（按语义标签找控件，走原生 COM 的 IUIAutomation；要求引擎带补丁 0003，见 §9）。

- [ ] 再双击一次。通过：第二个进程很快退出，原窗口回到前台（原窗口最小化时也恢复）。
- [ ] 密码行：按本机设置分别看"只用一次性密码""两种都用""只用固定密码""在本机接受""服务已停止"五种（`01-内容与逻辑说明.md` P1 区块 A 的表）。通过：标签和内容和表一致；点"复制"出现轻提示"已复制"，剪贴板里是对应内容；ID 旁的"复制"和双击 ID 也能复制 ID。
- [ ] 窗口尺寸、拖动、改大小、缩放：照 `03-实施方案.md` §5.2 M0 的几条（维护者手动看的见第 10 节）。

## 3. 连接框和最近列表

- [ ] 最近列表：列表行显示名称、ID、`用户名@主机名`、平台图标和在线状态；没有记录时显示"暂无最近连接的设备"；加载中有骨架行。在线状态只在窗口有焦点时刷新（每 6 秒一次）。
- [ ] 单击行选中，双击或回车连接，悬停时行尾出现"连接"。
- [ ] 连接框为空时"连接"不可点。输入完整 ID 回车：开新标签连接。输入名字（例如设备名的一部分）：列表变成"搜索结果"，第一行"连接到 ‹输入›"，高亮落在第一台匹配的设备上；没有匹配时显示"未找到匹配的设备"，回车走"连接到 ‹输入›"。上下键移动高亮，Esc 回到输入框。
- [ ] ID 后加 `/r`，或在"连接"下拉里选"经中继连接"。通过：这次经中继，标签标记"经中继"；对端配置里写入"始终经中继"（`peers\<ID>.toml` 的 `force-always-relay = 'Y'`），下拉里那一项下面有说明这一点的小字。
- [ ] 问号说明：点开列出能输入的几种（ID、IP、域名:端口、`ID@服务器`）。

## 4. 连接过程（会话页的状态面板）

每条看面板上的文字、按钮和两端日志。连接入口用连接框，或 `leapgate.exe --connect <ID> [--password <密码>] [--relay]`（交给已在运行的主窗口）。

- [ ] **直连**：两端都能直连时连接。通过：控制端日志 `used to establish IPv6 connection`（或其他直连）后 `handle_peer_info`；标签和工具栏标记"直连"，第一次连上轻提示"已建立直连"。
- [ ] **经中继**：`--relay` 或服务端临时强制中继。通过：`used to establish Relay connection`、没有 `leapgate ice:` 行；标记"经中继"、轻提示"已建立中继连接"。用了 `--relay` 的，测完把对端配置里的 `force-always-relay` 去掉。
- [ ] **自研 ICE 胜出**：控制端本地选项 `enable-ipv6-punch = 'N'`、`enable-udp-punch = 'Y'`。通过：`leapgate ice: selected …`，服务端 `ice_result` 同一行逐项一致；标记"直连"。
- [ ] **要密码**：不带密码连接。通过：面板两步进度"建立连接 ✓ → 验证身份"，密码框获得焦点，密码为空时"连接"不可点。
- [ ] **密码错误**：输错后回车。通过：密码框下红字"密码错误"。
- [ ] **输密码并记住**：勾"记住密码"、输对、回车。通过：短暂显示"已连接，正在等待画面…"，随后出画面；对端配置里存下了密码。
- [ ] **存过密码直接进**：断开后不带密码再连。通过：不出密码面板，直接登录。
- [ ] **2FA**：被控端开二次验证后连接。通过：验证码框，输满 6 位自动提交；输错红字"验证码错误或已过期"；对方开了受信设备时多一个"信任本机"。
- [ ] **等对方接受**：被控端审批方式设成"在本机接受"后连接。通过：面板"正在等待对方接受…"、"已等待 ‹n› 秒"和"取消"；被控端 CM 点"接受"后连上。
- [ ] **选择 Windows 用户会话**：被控端有多个用户登录时连接。通过：下拉列出会话，只有"连接"。
- [ ] **不安全连接**：连到没有端到端加密的对端。通过：警告文字、"继续"和"断开"，回车默认是"断开"。
- [ ] **出错文案**：连一个不存在的 ID。通过："未找到 ID 为 ‹ID› 的设备。…"，按钮"关闭标签""修改 ID"；"修改 ID"回到主页并把这个 ID 填进连接框、全部选中。Key 填错时："本机与服务器的密钥（Key）不一致，无法连接服务器。"，只有"关闭标签"。
- [ ] **断线后自动重试**：会话经中继进行中停掉被控端程序。通过：面板"连接已被远程设备断开。"和"‹n› 秒后重试（第 ‹k› 次）"，间隔 1、2、4…秒翻倍；被控端回来后自动连上。
- [ ] **对方断开**：在被控端 CM 点"断开连接"。通过：面板"对方已断开连接。"，按钮"关闭标签""重新连接"；标签显示"已断开"；"重新连接"能连上。
- [ ] **改用中继**：直连被重置时（开着代理或 VPN 时常见）。通过：出错面板有"改用中继"，点了以后经中继连上，并写入"始终经中继"。
- [ ] **对方重启后静默重连**：工具栏"操作 › 重启远程设备"并确认。通过：面板"远程设备正在重启，完成后将自动重新连接。"，最后一帧变暗；对方回来后自动连上。
- [ ] **1.5 秒唤醒锁屏**：被控端锁屏时连接。通过：连上后约 1.5 秒画面出现（程序给对方发了一个空的系统登录密码唤醒锁屏）；第一帧到之前就切走标签时不发。

## 5. 会话标签和输入

- [ ] 标签：一台设备一个；连接中显示转圈和"正在连接…"，出错显示"已中断"（会自动重试）或"连接失败"，对方断开后设备名变灰"已断开"。系统窗口标题跟着当前标签：主页"Leapgate"，会话"‹设备名› - Leapgate"。
- [ ] 标签"×"：断开并关掉标签（日志 `Exit io_loop`）。
- [ ] "+"：切到主页，光标在连接框里，直接打字就能搜索。
- [ ] `--connect` 交给已在运行的主窗口：窗口隐藏、最小化、被别的窗口挡住三种情况下，都会显示出来并到前台，开新标签或切到已有标签。
- [ ] 键盘只给当前标签：在 A 标签画面上按住 Shift，切到 B 标签再松开。通过：A 的远程设备上 Shift 先按下、切走时抬起（不会一直按着）。同一标签里按下松开，远程设备收到按下和抬起。
- [ ] 工具栏：默认态（固定、远程桌面、画面、操作、连接方式标记、断开、全屏、收起）；不固定时鼠标进入画面 5 秒后收起，收起后只剩拖动条（连接方式小点、全屏、展开）；"画面"里缩放两项和画质三档；"操作"里发送 Ctrl+Alt+Del 和重启远程设备（带确认）；对端只有一块屏时没有显示器按钮。
- [ ] 全屏：顶栏隐藏，工具栏最左显示设备名，拖动条多"最小化"；退出全屏恢复。
- [ ] 后台标签不推画面（V1）：两个会话推流时停在主页或别的标签，控制端 CPU、GPU 占用比停在会话标签时低。

## 6. 关闭

- [ ] 没有会话时关窗（便携版）：询问"关闭窗口？"，单选"退出 Leapgate / 在后台运行"、"记住此选择"、"取消""关闭"。
- [ ] 有会话时关窗（便携版，没改过"关闭窗口前确认断开会话"）：同一个确认里标题是"断开全部 ‹N› 个会话并关闭窗口？"，多一个"不再提示"，主按钮"断开"。
- [ ] 选"在后台运行"并确认：会话断开，窗口隐藏，进程照常当被控端；再双击程序或 `--connect` 把窗口找回来。
- [ ] 勾"记住此选择"后再关窗：不再问 Q6，按记住的做；勾"不再提示"后有会话时也不再确认。
- [ ] 无人值守用法：本地选项 `enable-confirm-closing-tabs = 'N'`、`leapgate-close-action = 'background'` 时，`leapgate-e2e.ps1 -Action CloseSessions` 给主窗口发 WM_CLOSE，会话全部断开、窗口隐藏、进程留着。

## 7. 引擎

- [ ] 4K、频繁重建采集的被控端（DXGI 每几秒失效一次的机器）连 5 分钟以上。通过：画面持续更新，控制端不崩溃（Windows 应用程序日志里没有 `leapgate.exe` 的 1000 号事件）。
- [ ] 开着讲述人（或一个不停遍历界面的 UI Automation 客户端），开、关会话标签和关窗确认。通过：不崩溃。
- [ ] 最新 stable 检查（`03-实施方案.md` §8.8）的第 3 步也用上面这个 4K 场景，只用 `--connect --password`，不开讲述人和 UI Automation 客户端。

## 8. 旧界面五项（过渡期，两端都用旧界面构建）

做法和判定沿用第二期清单 §7。切换后在装着新界面安装版的机器上跑，先按"准备"停掉安装版的服务和托盘。旧界面便携版的构建时间比安装版晚时，它的主页会出"升级"卡，不要点：点了会把安装版换回旧界面（`11-M8拆法.md` §4.4）。

- [ ] 连接（带密码，登录成功）。
- [ ] 强制中继（`--relay`）。测完去掉对端配置里的 `force-always-relay`。
- [ ] 文件传输两个方向，两边文件哈希一致。
- [ ] TCP 端口转发：映射到一个 HTTP 站点，curl 本地端口 200。
- [ ] 出口：被控端开"允许作为出口"，控制端 socks5h 和 HTTP CONNECT 都 200。
- [ ] 顺带：用一个空配置目录启动一次，日志 `Generated id` 是 9 位、不小于 268435456（默认 ID 加盐）。测完放回原配置。

## 9. 已知问题（写清单时）

- 新界面在自编引擎上语义树始终为空：UI Automation 只看到窗口和 `FLUTTERVIEW`，stderr 每次语义更新都报 "Accessibility bridge rebuilt after failed update: 0 will not be in the tree and is not the new root"。讲述人读不到控件，`leapgate-uia.ps1` 也找不到控件；无人值守脚本改用 `leapgate-post-input.ps1` 投递消息并按截图坐标操作。2026-10-31 已由引擎补丁 0003 修好（`无障碍语义树为空排查.md` §9）：换上新引擎以后，MSAA 和原生 COM 的 IUIAutomation 都能读到树。托管的 System.Windows.Automation 仍然看不到，所以 `leapgate-uia.ps1` 同日改成了 COM，Dump、Wait、Invoke 等操作已在新引擎上实测（同文档 §9.4）。
- 没写进本地选项时（新配置），有会话也不出"断开全部 ‹N› 个会话并关闭窗口？"，只问"关闭窗口？"。
- 新界面会话里，键盘事件（`keybd_event` 注入的 Shift、F12）没有发到远程设备；同样做法旧界面能发过去。真实键盘待维护者确认。

## 11. M2b：完整会话页和主页（2026-11-01 追加）

**11.1 03 §5.2 M2b 验收的几项**

**11.2 05 §1.1 每个区域一条**

会话页

- [ ] 退出后再双击同一个包。通过：不重新解压（解压目录里的文件时间不变），直接起来。
- [ ] 默认 ID 加盐：用发布构建、在一个空配置目录里起一次。通过：日志 `Generated id` 是 9 位，且不小于 268435456。测完放回原配置。
- [ ] 冷启动 `--connect`：没有 Leapgate 在运行时执行 `leapgate.exe --connect <B 的 ID>`。通过：主窗口起来并开标签连接；本机区的 ID、密码行和服务状态和双击启动时一致。不一致时记下显示的状态和日志。

## 21. 安装版（测试虚拟机）

按 `11-M8拆法.md` §5.3。测试虚拟机先回滚到干净快照，测完回滚。快照里管理员提权不弹框，所以取消 UAC 那条路只能在维护者自己的机器上看（见本节最后一条）。

- [ ] "安装"卡：在没装 Leapgate 的机器上双击便携包，点主页的"安装"。通过：卡片说明是"安装后，对方远程控制本机时也能操作用户账户控制（UAC）窗口。"，默认窗口下导航不被挤到栏底以下；点后便携版窗口约 1 秒内消失（安装在子进程里做，`client/LEAPGATE.md` §10.16），几秒后安装版的界面和托盘都起来。然后跑第二期清单 §4 第 3 条起的各条（安装目录、服务、卸载项、URL 协议、防火墙规则、快捷方式、进程、管道、服务配置目录）。卸载项的 `DisplayVersion` 是 Leapgate 的版本，不是上游版本（M8-5）。
- [ ] 设置沿用：安装前在便携版里记下 ID、固定密码、ID 服务器、API 服务器和 Key。通过：安装版里这几样都和便携版一样（安装脚本建服务时带 `--import-config` 导入当前用户的配置，`client/LEAPGATE.md` §10.16）；有变的写进验收记录和试用说明。
- [ ] "升级"卡：先装一份构建时间较早的、装在自定义路径；再双击新构建的便携包，点"升级"。通过：主页出现"已安装的 Leapgate 版本低于当前版本。"和"升级"；升级后程序仍在原来的自定义路径，选项不变。
- [ ] 覆盖安装：先装旧界面安装版，再用新界面便携包的"安装"装上去；之后反过来用旧界面再装一次。通过：前者安装目录里没有旧界面独有的文件（4 个插件 dll、一批 svg 和 ttf），服务拉起的连接管理小窗是新界面的；后者旧界面正常运行。
- [ ] 托盘"打开"：关掉主窗口、进程留在后台后，点托盘菜单的"打开"。通过：隐藏的主窗口回来。
- [ ] 来访小窗：从 A 连进测试虚拟机。通过：弹出的是新界面的小窗（窗口类名 `LEAPGATE_UI_CM`）。
- [ ] 交换控制方向：会话"操作"菜单里"交换控制方向"，确认。通过：两端的控制方向互换，会话正常。
- [ ] 链接：分别打开 `leapgate://‹ID›`、带 `/r` 的形式、`leapgate://connection/new/‹ID›`、`leapgate://file-transfer/‹ID›`，以及端口转发、RDP、摄像头、终端四种会话的链接；`leapgate.exe --file-transfer <ID>` 在主窗口已开着时再执行一次。通过：前四种分别开远程桌面、经中继的远程桌面、远程桌面、文件传输；后四种只出一条全局轻提示"暂不支持打开‹…›会话。"，不打开任何东西；`--file-transfer` 交给已开着的主窗口，开文件传输。
- [ ] 主页改固定密码：点密码行的"修改"。通过：先要求解锁（输入解锁 PIN，或"改用管理员权限解锁"），解锁后才打开"设置固定密码"。
- [ ] 设置页解锁：先设好解锁 PIN，再看传入连接各小节和"网络和服务器"。通过：导航上带"已锁定"，小节顶部写"已锁定。修改这些设置需要管理员权限。"和"解锁"；PIN 错时"PIN 错误"，对时解锁；离开设置页再回来重新上锁。
- [ ] 安装版停止和启动服务。通过：停止前确认写"本机将无法接受远程连接。Leapgate 将关闭并重新打开，所有会话和正在使用的出口都将断开。"；确认后服务结束、界面重开并写"服务已停止，本机无法接受远程连接"；"启动服务"后服务运行、界面重开。
- [ ] 保存失败：解锁后用管理员结束服务进程，再改一项权限。通过：该项下红字"无法保存设置"，开关回到原值，配置没有写入。
- [ ] 远程打印：点"安装打印机"。通过：构建里没带打印机驱动时写"无法安装 Leapgate 打印机。"和"重试"、带"技术细节"；补上驱动以后要看到"已安装"。
- [ ] 卸载：照第二期清单 §9 前两条。通过：服务、URL 协议、防火墙规则、卸载项、安装目录和快捷方式都删掉，用户配置和日志保留。
- [ ] 与原版共存：在测试虚拟机上装一份上游原版（下载后核对 sha256），照第二期清单 §6 走。新界面没有"Auto update"选项，§6 里依赖它的那条跳过。
- [ ] 外呼：照第二期清单 §5，"Auto update"那条同样跳过。第二期清单 §1~§3 里依赖内置默认服务器的几条，等注入了默认服务器的构建再测（M8-4）。
- [ ] 要在维护者机器上看的：点"安装"或"升级"后在 UAC 里点"否"。通过：卡片下写一行原因（例如"未获得管理员权限，未安装。"），按钮恢复，便携版不退出。
