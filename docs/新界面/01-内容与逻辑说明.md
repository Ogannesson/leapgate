- 这份说明不定颜色、字体、圆角、图标风格和动效，这些由设计师在两个风格方向里提。

## 要点

1. 桌面主窗口改成"一个主页标签 + 每台设备一个会话标签"。主页左栏放本机 ID、密码和能不能被连，右边是"连接框 + 设备列表"。设置不再单独开标签，并进主页左栏的导航。
2. 远程会话的连接过程不再弹一串模态框，改成会话标签里的分步状态面板，失败时直接说原因和下一步。
3. "直连还是经中继"常驻显示：标签上一个小标记，工具栏上一个可以点开的连接方式标记。
4. 出口做成主页里的独立一页："使用"一下就拿到本地代理地址，出口在后台运行，不用再开着一个 TCP 隧道窗口（§8 Q4、Q10）。
5. 被控端连接管理小窗还是独立的小窗口（它本来就是单独的进程，不受单窗口决定影响），权限加文字，授权后收成贴边小条（§8 Q5）。
6. 手机只保留控制端：首页就是设备列表，没有底部导航；一次一个会话；会话工具栏按"键盘 / 输入 / 画面 / 更多"重排。
7. 只对 RustDesk 官方有意义的东西（官网链接、Pro 专属入口、公共服务器提示、官方更新）一律去掉或改成 Leapgate 自己的，清单在 §5。

### 0.3 术语

| 术语 | 意思 |
|---|---|
| 控制端 | 发起连接、去看和操作别人电脑的一方 |
| 被控端 | 被别人远程控制的那台电脑 |
| ID | 每台设备在服务器上的编号，默认 9 位数字，界面上每 3 位空一格，例如 123 456 789 |
| 一次性密码 | 被控端自动生成、可以随时刷新的访问密码，适合临时让人连一下 |
| 固定密码 | 被控端主人自己设的访问密码，适合无人值守 |
| 审批方式 | 来访怎么放行：输对密码、本机有人点"接受"，或两种都行 |
| 密码方式 | 审批方式含密码时，认哪种密码：只认一次性密码、只认固定密码，或两种都认（上游叫"验证方式"） |
| 提权 / UAC | 便携版没有管理员权限，遇到 Windows 的管理员确认窗口（UAC）时控制方点不了；"提权"是请对方把这次会话升到管理员权限 |
| 隐私模式 | 控制方开启后，被控端的屏幕变黑或被遮住，被控端前面的人看不到控制方在做什么 |
| 只看模式 | 控制方只看画面，不发送任何键盘鼠标操作 |
| 相对鼠标模式 | 鼠标被锁在远程画面里，只发送移动的距离，给游戏一类程序用；按 Ctrl+Alt 退出 |
| 虚拟显示器 | 在没接显示器的 Windows 电脑上虚拟出一块屏幕，让远程画面有东西可看 |
| 受信设备 | 被控端开了二次验证（2FA）时，勾过"信任这台设备"的控制端以后免输验证码 |
| 被策略固定 | 某个选项被构建或管理员写死，界面上灰显、不能改，旁边说明原因 |
| SOCKS5 / HTTP 代理地址 | 出口在本机开的代理地址，例如 `socks5h://127.0.0.1:21180`；`socks5h` 表示域名也交给代理去解析 |
| 直连 | 两台电脑之间直接连通，包括同一局域网内直连和"打洞"直连 |
| 打洞 | 两端都在路由器后面时，借服务器交换地址后直接连通的技术；Leapgate 自己实现了一套（自研 ICE，architecture §3.8） |
| 中继 | 两端连不上时经服务器转发。能用，但一般比直连慢，也占服务器流量 |
| 出口（应用出口） | 把另一台设备当作上网出口：本机设了代理的程序，流量从那台设备的网络出去，只走 TCP（architecture §3.9） |
| 出口目录 | 服务器列出的、当前账号能用的出口设备，只列此刻在线并开着出口的 |
| 地址簿 | 账号下保存的设备清单：一本个人簿，加上别人共享给你的共享簿 |
| 会话 | 一次连接。类型有远程桌面、文件传输、终端、摄像头查看、TCP 隧道（端口转发） |
| TCP 隧道 | 把本机的一个端口接到对方（或对方网络里）的某个端口，例如远程桌面协议 RDP |
| CM | 连接管理小窗（Connection Manager）：被控端有人连进来时弹出，用来接受、拒绝、断开、调权限 |
| 标签 | 主窗口顶部的应用内标签：一个主页标签，加若干会话标签 |

## 1. 谁在用、主要场景

用户很少：维护者本人（几台自己的电脑，一部手机），几个朋友，以及偶尔被帮忙的家人。家人是最不熟悉软件的一方，界面要让他们"打开就知道把什么告诉对方"。

| 场景 | 关键路径 | 目标步数 | 上游现在 |
|---|---|---|---|
| S1 控制自己的另一台电脑 | 打开 Leapgate → 设备页默认显示"最近"，找到那台 → 点卡片上的"连接"（或双击卡片）→ 存过密码的直接进画面 | 2 步 | 只能双击连接，单击卡片没有任何反应（`flutter/lib/common/widgets/peer_card.dart:64-80`） |
| S2 帮家人朋友看电脑：被帮的一方 | 打开 Leapgate → 首屏左上角就是本机 ID 和一次性密码，点"复制"发给对方或念给对方 → 对方连进来时 CM 弹出；审批方式含点击时点"接受" → 结束时点"断开" | 2~3 步 | 复制只能双击，界面上没有复制按钮（`flutter/lib/desktop/pages/desktop_home_page.dart:229-232`、`:324-329`） |
| S2 帮家人朋友看电脑：帮忙的一方 | 连接框输入对方 ID → 回车 → 在会话标签里输密码 → 进画面 | 3 步 | 同样 3 步，但中间是一串模态框 |
| S3 用别人的电脑当出口上网：一次性准备 | 出口那台的主人：设置 → 安全 → 打开"允许作为出口"；要无人值守就设固定密码、审批方式选只用密码（第二轮设置页） | — | 同 |
| S3 用别人的电脑当出口上网：每次使用 | 主页 → 出口 → 在目录里选一台 → "使用" → 当场输那台的设备密码（或等对方点接受，存过密码就跳过，§8 Q10）→ 卡片上出现本地代理地址 → 复制 → 在浏览器里设代理（同一台设备以后沿用同一个端口，浏览器不用重设） | 应用内 4 步 | …菜单 → 出口节点 → 使用 → 打开 TCP 隧道窗口 → 添加出口节点 → 填端口 → 确定 → 复制，至少 6 步，隧道窗口还不能关（`flutter/lib/leapgate/exit_nodes.dart:73-76`、`flutter/lib/leapgate/exit_tunnel.dart:47-67`） |
| S3 没登录账号时 | 连接框输入设备 ID → 连接按钮的下拉选"用作出口"（或在出口页"用 ID 指定出口"） | 3 步 | 只能先开 TCP 隧道再加出口 |
| S4 在手机上临时连一下 | 打开 App → 列表默认"最近" → 点设备 → 输密码（存过就跳过）→ 全屏画面 → 用键盘按钮打字 → 断开 | 2~3 步 | 单击卡片要等约 300 ms 才连接（同时挂了单击和双击，`flutter/lib/common/widgets/peer_card.dart:64-80`） |
| S5 被控端主人想知道"谁连着我"、随时踢掉 | CM 在会话期间一直在（收成贴边小条）→ 点"断开"；主窗口本机区也显示"有 N 人正在远程控制" | 1 步 | 密码直接通过的来访，CM 3 秒后自动最小化到任务栏（`flutter/lib/models/server_model.dart:581-586`）；点"接受""接受并提权""提权"时当场最小化（`flutter/lib/desktop/pages/server_page.dart:1031`、`:1094`、`:1117`）。两种都容易让人忘了有人连着 |

出口这条路径没登录也能走，这是第四期的决定（第四期设计决策清单 A2：允许手填 ID 使用出口，只是看不到目录）。

## 2. 信息架构

### 2.1 桌面主窗口：一个窗口，顶部是应用内标签

```
┌────────────────────────────────────────────────────────────────────────┐
│ [应用图标] [⌂ 主页 ①] [书房台式机 ·直连 ×] [妈妈的笔记本 ·中继 ×] [+]    ─  □  × │ ← 顶栏（标签栏 + 窗口按钮）
├──────────────────┬─────────────────────────────────────────────────────┤
│ 本机               │ [ 输入 ID，或搜索设备……                ] [连接 ▾]     │ ← 连接框
│ ID  135 792 468 ⧉ │ 最近  收藏  局域网  地址簿  同组设备        视图 排序 … │ ← 分类和列表工具
│ 一次性密码 a1b2c3 ⧉⟳│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                  │
│ ● 可以被连接        │ │ 卡片  │ │ 卡片  │ │ 卡片  │ │ 卡片  │                  │ ← 设备列表
│ 有 1 人正在控制 查看 │ └──────┘ └──────┘ └──────┘ └──────┘                  │
│ ─────────────    │                                                     │
│ ▸ 设备             │                                                     │
│ ▸ 出口  ①          │                                                     │
│ ▸ 设置             │                                                     │
│                  │                                                     │
│ (张) 张三  ▾       │                                                     │ ← 账号区
└──────────────────┴─────────────────────────────────────────────────────┘
```

**顶栏**（自绘标题栏，和 Windows 窗口按钮在同一行，高约 40 逻辑像素）

- 最左是 16 像素左右的应用图标，没有交互（和 Windows 习惯一致）。应用图标现在是占位图（提交说明写明等视觉定稿后再换），这一轮不设计 Logo，样稿里画一个占位方块即可（§7.1）。
- 主页标签：固定在图标右边，不能关，只用图标或"主页"二字。有后台连接在运行时，标签上显示数量：第一轮只有出口，第二轮加上 TCP 隧道后数的是"出口 + TCP 隧道"的总数（它们不占会话标签，§8 Q4）。
- 会话标签：一台设备一个（§8 Q1）。标签上是设备名、连接方式小标记、未读聊天数、关闭按钮。悬停显示完整名称、ID，以及每个打开着的视图各自的连接方式。
- 标签上的连接方式标记：标签里只有一个视图时就是它的连接方式；有几个视图（例如远程桌面直连、文件传输经中继）时显示最差的那个，顺序是"未加密"最差、"经中继"其次、"直连"最好，悬停时逐个列出。工具栏上的标记只说当前视图（§3.2 区块 B）。
- 会话标签的状态：连接中（转圈）、直连、经中继、未加密（警告）、出错或等待重试（警告标记，悬停显示原因和倒计时）、已断开（设备名变灰）、有未读聊天（数字）。
- 标签挤不下时横向滚动，右端一个下拉列出全部标签（上游已有，`flutter/lib/desktop/widgets/tabbar_widget.dart:1340` 起的 `_TabDropDownButton`）。
- "+"：切到主页，并把光标放进连接框。上游的"+"只是把主窗口提到前台（`flutter/lib/desktop/widgets/tabbar_widget.dart:1324-1338`），单窗口后自然变成切标签。
- 拖动空白处移动窗口，双击空白处最大化或还原。窗口四边都能拖动改大小（上游隐藏了系统标题栏，上沿的拖动区由 Flutter 补上，`flutter/lib/common.dart:4048-4054`，新顶栏要保留这一点）。
- 系统窗口标题（任务栏上显示的）跟着当前标签：主页是"Leapgate"，会话标签是"‹设备名› - Leapgate"。
- "切到下一个 / 上一个标签"的快捷键把主页标签算在内，主页是第一个。
- 全屏时整条顶栏隐藏，设备名和连接方式改在会话的浮动工具栏里显示。

**主页标签的内容**：左栏 + 右侧内容区。

- 左栏宽度固定（约 240 逻辑像素），从上到下：本机区（ID、密码、能不能被连、正在连入的人）→ 本机提示卡（需要时才有）→ 导航（设备、出口、设置）→ 账号区。
- 左栏的高度：账号区固定在底部，其余部分在内容超高时整体纵向滚动（上游左栏也是整栏滚动）。最小窗口 960×600 下，没有提示卡时本机区、导航、账号区要不滚动就放得下；出现提示卡时允许滚动。
- 右侧内容随导航切换：设备（默认）、出口、设置（第二轮）。
- 设置从"单独一个标签"改成主页里的一页。理由：上游打开设置会多出一个标签，而且有三个入口都通向设置（标签栏右侧的设置图标、ID 板右上角的"⋮"、密码板的铅笔，`flutter/lib/desktop/pages/desktop_tab_page.dart:99-107`、`flutter/lib/desktop/pages/desktop_home_page.dart:256-279`、`:374-375`），合成导航里的一项就够了。

**会话标签的内容**（§8 Q1）

- 一个会话标签就是"我在为哪台电脑干活"。标签里可以有远程桌面、文件传输、终端、摄像头四种视图。
- 视图切换控件在每种视图里都有：远程桌面视图放在浮动工具栏最左边；文件、终端、摄像头视图顶部各有一条窄的标题栏，切换控件放在它的最左边。控件展开后列出四种视图，已打开的标出连接方式，没打开的写"未打开"，点了才建立那条连接。标签的右键菜单里也有"打开文件传输 / 终端 / 摄像头"。
- 第一次从设备卡片打开哪种，标签就先显示哪种。已经有远程桌面会话时，打开其他视图复用同一个连接令牌，不用再输密码（上游 `connectWithToken`，`flutter/lib/common/widgets/toolbar.dart:580-610`）。
- 第一轮只画视图切换控件和它展开后的样子；文件、终端、摄像头视图本身第二轮画（§6）。
- 出口和 TCP 隧道不占会话标签：它们是后台运行的连接，放在主页的"出口"页管理（TCP 隧道管理是第二轮）。
- 一台设备的多块显示器在同一个标签里切换，或者合并显示。"各显示器独立窗口""用上我所有的显示器"都需要多个窗口，按单窗口方案去掉（§8 Q11）。

**窗口关闭**

- 有会话开着时点关闭（不管几个）：页内确认"断开全部 N 个会话并关闭窗口？"，带"以后不再提示"勾选（沿用上游"关闭多个标签前确认"那个选项，第二轮设置里也能改回来）。远程会话不能在看不见的窗口里继续跑。
- 出口在用时，同一个确认里多一句"N 个出口会在后台继续运行"。
- 没有会话时：安装版隐藏到托盘；便携版先问一句（§8 Q6）。有会话的便携版，两个问题合在同一个确认里（断开会话，然后选退出还是留在后台），不连着弹两次。
- 出口：安装版关窗后继续在后台运行，点托盘"打开"回到窗口。托盘是单独的进程，现在只经进程间接口读被控会话数（`src/tray.rs:252-292`），读不到主窗口进程里的出口，所以托盘上**不**显示出口数；要显示得补接口，第一轮不做。

### 2.2 手机：首页就是设备列表

```
┌──────────────────────────┐
```

- 设置从首页右上角进入（第二轮）。
- 文件传输、终端、摄像头从设备的操作面板进入，是第二轮的页面。

## 3. 第一轮页面

每页按同样的顺序写：用途、首屏先看什么、各区块、操作、状态、和上游比的变化。

### 3.1 P1 桌面主窗口（主页标签）

**用途**：两件事，一是让别人连进来（报 ID 和密码），二是去连别人（找设备、发起连接）。另外是出口的入口和账号状态。

**首屏先看什么**（按优先级）

1. 本机 ID 和密码：被帮的人只需要这两样，而他们最不熟悉软件，所以放在左上角最显眼的位置。
2. 连接框：控制端每次连新设备都从这里开始。
3. 设备列表，默认"最近"：连自己的设备时最常用。
4. 本机能不能被连（服务状态）。
5. 正在连进来的人。
6. 账号状态（登录后才有地址簿、同组设备、出口目录）。
7. 本机提示卡（例如便携版没安装）：位置在本机区下面，出现时要比设备列表醒目，因为它影响"别人能不能连我"。

#### 区块 A：本机区（左栏顶部）

回答"别人怎么连我、现在能不能连上我"。

- **ID**：大号显示，每 3 位空一格，等宽数字；右边一个"复制"按钮，双击 ID 也能复制，复制后轻提示"已复制"。还没拿到 ID 时显示"正在生成…"。上游 ID 板右上角的"⋮"其实是打开设置（`flutter/lib/desktop/pages/desktop_home_page.dart:256-279`），去掉。
- **密码行**：标签和内容按本机的审批方式、验证方式变化。上游标签永远写"一次性密码"，没有一次性密码时只显示"-"，不说原因（`flutter/lib/desktop/pages/desktop_home_page.dart:295-319`、`flutter/lib/models/server_model.dart:249-252`）。

  | 本机设置 | 标签 | 内容 | 操作 |
  |---|---|---|---|
  | 用一次性密码（审批方式不是"仅点击"） | 一次性密码 | 密码明文 | 复制、刷新 |
  | 两种密码都用 | 一次性密码 | 密码明文，下面一行小字"也可以用固定密码" | 复制、刷新 |
  | 只用固定密码 | 固定密码 | "已设置（不显示）" | 修改 |
  | 审批方式"仅点击" | 访问方式 | "对方连进来时，需要你在这台电脑上点'接受'" | — |
  | 服务已停止 | 一次性密码 | "服务已停止" | — |

  "修改"直接打开设置固定密码对话框（§3.1 区块 K）。上游要先跳到设置的安全页，解锁后往下翻过权限卡和出口卡，才找到"设置固定密码"按钮（`flutter/lib/desktop/pages/desktop_home_page.dart:374-375`、`flutter/lib/desktop/pages/desktop_setting_page.dart:1323`）。另放一个"更多访问设置"链接到设置的安全页（第二轮）。

- **服务状态行**：从上游右栏底部搬过来（`flutter/lib/desktop/pages/connection_page.dart:324-325`），和 ID 放在一起，因为它回答的就是"别人现在能不能连我"。

  | 状态 | 文案 | 操作 |
  |---|---|---|
  | 就绪 | 可以被连接 | — |
  | 正在连服务器 | 正在连接 Leapgate 服务器… | — |
  | 连不上服务器 | 连不上服务器，正在自动重试。请检查网络 | — |
  | 服务已停止 | 服务已停止，别人连不进来 | 启动服务 |

  "连不上服务器"不放"重试"按钮：上游这一行只是每秒查一次状态（`flutter/lib/desktop/pages/connection_page.dart:57-59`），和服务器的连接本来就在后台自己重连；安装版的这条连接在服务进程里，要从界面触发重试还得新加进程间接口，不值得。

  上游用同一种橙色表示"连接中"和"服务已停止"，离线设备的在线点也是这个橙色（`flutter/lib/desktop/pages/connection_page.dart:122-127`、`flutter/lib/common/widgets/peer_card.dart:1474`）。新设计里这几种含义要用不同的颜色或形状区分。
- **正在连入**：有人连着时显示"有 N 人正在远程控制这台电脑"和"查看"（把 CM 提到前面）。人数现在只有远程桌面的连接数（`flutter/lib/desktop/pages/connection_page.dart:187` 的 `video_conn_count`），文件传输和出口会话不算；"查看"要一个新的进程间接口（§4.6）。按第四期 F12，这里不常驻"本机已允许作为出口"的提示，只有正在用的出口会话才出现在 CM 里。

#### 区块 B：本机提示卡（本机区下方，需要时才出现）

回答"这台电脑还有什么要处理"。一次只显示一张（上游 Windows 上也是一次一张）。

- 便携版没安装：说明"便携版作为被控端时，有些情况下不能正常工作（例如遇到系统的管理员确认窗口），建议安装"，按钮"安装"（`flutter/lib/desktop/pages/desktop_home_page.dart:461-468`）。
- 已安装的版本比当前程序旧：按钮"升级"。
- 系统错误：显示错误原文，不带按钮。
- 颜色跟随主题。上游是写死的粉紫渐变（`flutter/lib/desktop/pages/desktop_home_page.dart:614-617`）。
- 新版本卡、macOS 和 Linux 的卡片都去掉，理由见 §5。

#### 区块 C：导航

设备（默认）、出口、设置。"出口"旁边显示正在使用的出口数（和主页标签上的数第一轮相同，第二轮主页标签再加上 TCP 隧道）。

#### 区块 D：账号区（左栏底部）

回答"我登录了没有、登录的是谁"。上游首页看不出登录状态，登录入口散在地址簿、同组设备、设置三处，退出只能去设置（`flutter/lib/common/widgets/address_book.dart:42-45`、`flutter/lib/common/widgets/my_group.dart:33-36`、`flutter/lib/desktop/pages/desktop_setting_page.dart:2276-2286`）。

- 没登录："登录"按钮，下面一行小字"登录后可以用地址簿、同组设备和出口目录"。
- 已登录：头像 + 显示名，点开菜单：账号信息（@用户名）、退出登录（页内确认）。头像用显示名的第一个字（中文名取第一个汉字，例如"张三"取"张"；英文名取首字母大写）。
- 登录对话框见区块 K。

#### 区块 E：连接框（设备页顶部）

回答"我要连哪台、用什么方式连"。

- 一个输入框，提示"输入 ID，或搜索设备名"（合并连接框和列表搜索，§8 Q2）。桌面和手机用同一套规则，只有一种展示：不另外浮出下拉，下面的列表本身就是搜索结果。
- 输入框里有内容时，下面的列表变成"搜索结果"：
  - 范围是全部分类（最近、收藏、局域网、地址簿、同组设备），同一个 ID 只出现一次，每张卡片标出它来自哪个分类。上游的下拉候选也是跨分类找的（`flutter/lib/common/widgets/autocomplete.dart:97-150`）。
  - 结果最上面固定一行"连接到 ‹输入的内容›"（右侧带"⋯"，可以选别的连接方式），后面是匹配的设备。
  - 匹配范围统一成 ID、别名、主机名、用户名、备注（上游下拉候选不匹配备注、列表搜索在地址簿里匹配备注，两边不一致，`flutter/lib/desktop/pages/connection_page.dart:393-404`、`flutter/lib/common.dart:1680-1700`）。
  - 某些分类还没加载过时（例如地址簿），结果末尾一行"正在加载其他分类…"带转圈。
  - 清空输入就回到原来选中的分类，分类选择不受搜索影响。
- 键盘：在输入框里按下键进入结果列表，上下键移动，回车执行高亮的那一行，Esc 回到输入框。打字时默认高亮哪一行：
  - 输入和某台设备的 ID 完全一样：那台设备。
  - 输入看起来像地址（纯数字 ID、IP、`域名:端口`，或带 `@服务器`）：第一行"连接到 ‹输入›"，所以"输 ID 回车"的老习惯不变。
  - 其他（例如输的是"书房"这样的名字）且有匹配的设备：第一台匹配的设备；没有匹配时仍是"连接到 ‹输入›"。这样按名字搜索后回车，不会拿名字当 ID 去连。
- 输入框旁一个问号，点开说明能输入什么：ID、对方 IP（直连）、域名:端口、`ID@服务器`（上游 id_input_tip）。
- "连接"按钮带下拉：远程桌面（默认）、文件传输、终端、摄像头、TCP 隧道、RDP、用作出口、经中继连接。第一轮只画这些菜单项；TCP 隧道和 RDP 点了以后去的隧道管理是第二轮页面。
- "经中继连接"的文案要说实话：选了以后，这台设备以后每次都经中继（菜单项下面一行小字"以后连这台都经中继，可在设备菜单里取消"）。上游在 ID 末尾加 `/r` 的隐藏用法也是这样：它让这次强制走中继，连上后写进这台设备的"始终经中继"选项（`src/client.rs:2965-2968`、`:2999-3001`、`:3721-3726`）。`/r` 后缀照样能用。
- 输入为空时"连接"按钮不可点。上游点了没有任何反应。
- 不再自动填上次连接的 ID（上游 `mainGetLastRemoteId`），上次连的设备排在"最近"的第一张。上游每次发起连接时还会把 ID 写回主窗口的输入框（`flutter/lib/common.dart:2584-2594`），合并以后这会把列表过滤成只剩那一台，也一起去掉。

#### 区块 F：设备列表

回答"我有哪些设备、哪台在线、怎么连"。

**分类**：最近、收藏、局域网、地址簿、同组设备。用文字分段，不再只有图标（上游名字只在悬停提示里，`flutter/lib/common/widgets/peer_tab_page.dart:163-172`）。"同组设备"就是上游的"可访问的设备"：同在一个"共享设备"用户组里的人互相看得到对方的设备（architecture §3.6），改名是为了说清它是什么。

**列表工具**（分类同一行的右侧）

- 视图：卡片 / 列表两种。上游的"小卡片"和"列表"内容几乎一样，合并。
- 排序：名称、ID、用户名、在线状态（"最近"不排序，保持时间顺序）。"名称"按卡片上显示的名字排（别名，没有别名用主机名，再没有用 ID）。上游的四种是远程 ID、远程主机、用户名、状态（`flutter/lib/common/widgets/peers_view.dart:377-391`）：用户名保留；"远程主机"换成"名称"，因为卡片上先显示别名，按主机名排看起来像乱序。上游按状态排序的比较函数不合法，结果不稳定（`flutter/lib/common/widgets/peers_view.dart:389-391`），新实现要修。
- 多选、刷新（地址簿和同组设备）、标签筛选开关（地址簿）。
- "视图"菜单里还管：显示哪些分类、分类顺序。上游要右键分类栏或拖动，很难发现（`flutter/lib/common/widgets/peer_tab_page.dart:296-357`）。
- 视图、排序、分类显示被策略固定时，对应项灰显并说明（上游 `isOptionFixed`）。

**设备卡片**（卡片视图和列表视图显示同样的字段）

- 名称：别名，没有别名用主机名，再没有用格式化的 ID。
- 在线状态：圆点加文字（在线 / 离线），离线不要用警告色。
- 第二行：`用户名@主机名`；地址簿和同组设备里有备注时再加一行备注。
- 平台图标：只有 Windows、macOS、Linux、Android 四种（`flutter/lib/consts.dart:37-40`）。iOS 不能被控制，不会出现在设备列表里。上游按"ID + 平台"算出一个底色色块，新设计要不要保留由设计师定，桌面和手机保持一致。
- 标签：色点加标签名，标签名用正文颜色。标签颜色是用户在色轮上随便选的，不能拿它当文字或大块背景的颜色，否则在某一套主题里会看不清。共享簿里存了密码的显示一个钥匙图标；收藏的显示星标。
- 能显示的字段以设备数据为准（`flutter/lib/models/peer_model.dart:8-24`）：**没有**最后在线时间、延迟、上次是直连还是中继、能不能当出口、系统版本，样稿里不要画这些。
- 交互：悬停时卡片上出现"连接"按钮和"⋯"；单击选中（有选中态）；键盘焦点有焦点态，上下移动、回车连接；双击连接。地址簿里的设备连接时自动带上共享密码（上游已有）。
- 在线状态只查屏幕上看得见的卡片，自建服务器每 6 秒一次，窗口失焦就停（`flutter/lib/common/widgets/peers_view.dart:313-346`）。刚加载时在线点可以先是中性的"查询中"。

**卡片的"⋯"菜单**：上游是 10~16 项平铺，连接方式和管理项混在一起（`flutter/lib/common/widgets/peer_card.dart:958-1348`）。新菜单分四组：

| 组 | 项 | 出现条件 |
|---|---|---|
| 连接方式 | 远程桌面、文件传输、终端、终端（管理员）、摄像头、TCP 隧道、用作出口、RDP（右侧可编辑 RDP 设置） | 终端（管理员）只在对端是 Windows；TCP 隧道对端不是安卓；用作出口只在对端是 Windows（只有 Windows 被控端能当出口，`libs/leapgate/src/exit/mod.rs:78-80`）；RDP 两端都是 Windows |
| 这台设备 | 始终经中继连接（勾选）、网络唤醒、创建桌面快捷方式 | 网络唤醒只在局域网分类；快捷方式只在 Windows |
| 整理 | 重命名、加入或移出收藏、加入地址簿、编辑标签、编辑备注、设置共享密码、忘记密码、在哪些地址簿里 | 按分类和权限，见下 |
| 危险操作 | 删除（最近：删记录；收藏：移出；局域网：移除；地址簿：删条目） | 同组设备没有删除 |

- 各分类的差异沿用上游：局域网没有重命名和忘记密码；同组设备只有连接方式和"加入地址簿"；共享簿只读时没有整理组。
- 规则统一成两条：平台或对端版本不支持的项**隐藏**；权限不够的项**灰显并说明原因**，例如"这本地址簿是只读的"。上游两种做法混着用。
- 连接框里手输的 ID 不知道对端平台，"连接到 ‹输入›"那一行的连接方式菜单列出全部项，对端不支持时由连接结果说明（§4.3）。
- 菜单里要再开小对话框的几项（重命名、单台删除确认"删除'‹名称›'？"、RDP 设置：端口、用户名、密码）照 §4.4 的通用对话框样式画，不单独出图。

**多选**：工具里的"多选"进入。整行换成多选条：删除、加入收藏（最近）、加入地址簿（已登录）、编辑标签（地址簿）、"已选 N 台"、全选、退出。按住 Shift 点击选一段。删除先页内确认。

**列表的状态**

| 状态 | 显示 |
|---|---|
| 加载中 | 卡片位置的骨架或转圈 |
| 空：最近 | "还没有连过任何设备。在上面输入对方的 ID 开始第一次连接。" |
| 空：收藏 / 局域网 / 地址簿 / 同组设备 | 各一句说明，例如局域网"没有发现同一网络里的设备" |
| 没登录（地址簿、同组设备） | "登录后可以看到你的地址簿" + 登录按钮 |
| 网络错误 | "连不上服务器" + 重试 |
| 服务器报错 | 列表上方一条可关闭的横幅 + 重试。上游的横幅没有重试按钮（`flutter/lib/common/widgets/address_book.dart:55-64`） |
| 搜索无结果 | 只剩第一行"连接到 ‹输入的内容›"，下面一句"没有匹配的设备" |
| 超过 1000 台 | 列表底部"只显示了前 1000 台，请用搜索缩小范围"。上游静默截断（`flutter/lib/common/widgets/peers_view.dart:238`） |

#### 区块 G：地址簿（分类之一）

回答"我存了哪些设备、这本簿我能不能改"。

- 顶部一行：地址簿切换下拉（"我的地址簿"排第一，共享簿按名字排，下拉里能搜索），旁边用文字写权限"只读 / 可编辑 / 完全控制"和所有者。上游只用几个小图标表示权限（`flutter/lib/common/widgets/address_book.dart:144-184`）。
- 标签筛选条：第一个是"未标记"，其余是标签（色点 + 名字）；可多选，选中态不要用标签色铺满底色（见区块 F 的标签规则）；"更多"里切换"同时满足所有选中的标签"。
- "更多"菜单：添加设备、添加标签、取消选择所有标签、与最近会话同步（勾选）、按交集筛选（勾选）。只读簿隐藏写操作。
- 在标签上右键：重命名、改颜色、删除（可写时）。改颜色是一个取色小对话框（一排预设颜色加自定义），第二轮细化。

**正在使用**（每个在用的出口一张卡片，一台设备最多一张）

- 设备名和 ID。
- 状态（见下表）和连接方式（直连 / 经中继）。
- 本地代理地址：两个复制按钮"复制 SOCKS5 地址"（`socks5h://127.0.0.1:端口`）、"复制 HTTP 地址"（`http://127.0.0.1:端口`）。不给 `socks5://`，那样控制端会在本地解析域名（第四期 F1）。

- 卡片上的通知区：单个目标被对方拦下时出现一条不打断的提示，同一原因只提示一次。现在被控端只回一条合并的原因（目标在对方局域网里、是对方本机、或对方网络的 DNS 返回了假地址，三种共用一条，`libs/leapgate/src/exit/mod.rs:25`），控制端也只知道程序要访问的域名或地址，所以文案是："对方拦下了一个访问：目标在对方的局域网里、是对方本机，或者对方网络的 DNS 给了假地址。要访问对方局域网，请对方在出口设置里放行对应网段。"通知里**不**显示访问目标：一是现在拿不到被拦的具体地址；二是第四期 C13 定了控制端日志不记访问目标，界面跟着这个取向走。以后真要显示，也只能放在内存里显示、不写日志。程序自己送来 198.18 开头的假地址时，单独一条："目标是本机代理软件的假地址，请在程序的代理设置里改用远程解析（socks5h）"（第四期 C12）。

**点"使用"之后**（§8 Q10 推荐方案，样稿照这个画）

- 卡片马上出现在"正在使用"里，本地代理开在这台设备的端口上，同时就去登录对方：状态依次走"正在连接 → 要密码 / 等对方接受 → 正在验证 → 在用"。用户就在出口页上，密码框出现在眼前。
- 现在的实现不是这样：出口隧道要等第一条本地连接进来才去登录（`src/leapgate_hooks/exit.rs:43-44` 的注释，第四期 C5、C9），端口转发窗口打开时只开本地监听、不连对方（`src/ui_session_interface.rs:1987-2030`）。照现在的做法，要密码或等对方接受会在用户切到浏览器、第一次上网时才出现，出口页不在眼前。所以要改 Rust：第一次登录在点"使用"时做；之后断线照 C9，由下一条本地连接触发重连。
- 重连时如果又要密码（没勾"记住密码"）或要对方接受，卡片进入相应状态，主页标签和导航"出口"上的数字旁加一个提醒标记，让人知道要回出口页处理。
- 端口怎么给：每台设备记一个端口。第一次用某台设备时，预填一个建议值：第一个是 21180，之后依次取 21181、21182…里还没被其他出口卡片用的；以后再用这台设备沿用它的端口，浏览器的代理设置就不用改。端口被别的程序占着时**不**自动换，进"端口被占用"让用户改（第四期 A10：被占用就报错，不自动换端口，`src/leapgate_hooks/exit.rs:53`）。
- 程序重启后不自动恢复"正在使用"的出口，免得一打开 Leapgate 就去连别人的电脑；再点一次"使用"即可，端口还是原来的。

- 只看模式下和输入有关的项灰显，说明"只看模式下不能操作"。
- 上游"控制动作"里的"传输文件、查看摄像头、终端、TCP 隧道"（`flutter/lib/common/widgets/toolbar.dart:589-610`）：前三个变成视图切换，TCP 隧道去出口页（第二轮的隧道管理）。
- "备注"保留在"操作"最后：服务端接得住会话中的备注（`server/src/api/audit.rs:350-370`）。会话结束时询问备注的那个对话框去掉，见 §5。
- "按远程分辨率调整窗口"（上游 Adjust Window）去掉：单窗口里调整整个主窗口的尺寸会影响其他标签，"适应窗口"和全屏能替代。上游改分辨率 3 秒后会在窗口没最大化、没全屏时自动执行一次 Adjust Window，这个自动行为也一起去掉，改完分辨率窗口尺寸不变。

#### 区块 C：画面区

- 远程画面按缩放方式显示，四周的空白用中性底色。

- 安卓对端的导航浮条（返回、主页、最近任务），可拖动，由"输入"菜单开关。

- 画面上各种东西的位置和叠放顺序（从下往上）：远程画面 → 质量数据浮层（左上）→ 相对鼠标提示（顶部居中，这时工具栏是隐藏的）→ 浮动工具栏（顶部居中）→ 会话通知（右上，工具栏下方）→ 聊天面板（可拖动）→ 工具栏菜单和连接方式详情 → 连接过程面板 → 对话框遮罩。同一时间只开一个菜单或弹层，打开新的会关掉旧的。

- 关整个窗口的确认见 §2.1。
- 上游有三种不同的关闭确认（单个会话、多个标签、带备注的结束框），文案和按钮都不一样（`flutter/lib/common/widgets/dialog.dart:23`、`flutter/lib/desktop/widgets/tabbar_widget.dart:882`、`flutter/lib/common/widgets/dialog.dart:1637`），统一成一种。

- 会话标签的各种状态排在一条标签栏里：连接中、直连、经中继、未加密、出错等待重试、已断开、有未读。

### 3.3 P3 被控端连接管理小窗（CM）

**用途**：被控端有人连进来时，让这台电脑前的人知道"谁在连我、在做什么"，并且能接受、拒绝、断开、临时收回权限。

**它不在主窗口里**：有来访时，被控服务用 `--cm` 参数另起一个进程打开这个小窗（`flutter/lib/main.dart:102-104`、`src/server/connection.rs:6409`），主窗口没开也会弹。所以单窗口、应用内标签的决定管不到它，新设计还是按一个独立的置顶小窗来画，不能画成主窗口里的标签或抽屉。

**首屏先看什么**

1. 谁在连：名字、ID、头像。
2. 我要做什么：请求中是"接受 / 拒绝"，已连接是"断开"。
3. 对方在做什么：会话类型（远程控制、文件传输、终端、端口转发、作为出口）和已连接时长。
4. 对方能做什么：权限开关。
5. 聊天、文件操作记录。

**尺寸**：紧凑态约 300~320 宽、500 高，贴屏幕右上角，置顶；打开聊天或文件记录后向左展开到约 700 宽（上游 300×490 和 700×490，`flutter/lib/consts.dart:354-355`）。

#### 区块

- **顶部**：可拖动的标题区，右边"收起"（收成贴边小条，代替上游的最小化按钮）和"关闭"。
- **来访标签**：每条连接一个标签（和上游一样），同一个人同时开着远程桌面和文件传输就是两个标签，标签上是会话类型图标、名字和未读数；悬停显示连接编号（上游悬停 1 秒显示）。只有一个连接时也显示标签，保持位置稳定。
- **信息头**：头像（没有就用名字的第一个字，规则同 §3.1 区块 D）、名字、ID、会话类型、状态行（"请求连接你的电脑…" / "已连接 00:12:34" / "已断开"）、右上角聊天或文件记录按钮（已授权后才有）。颜色跟随主题，上游是写死的蓝色渐变（`flutter/lib/desktop/pages/server_page.dart:466-469`）。
- **出口会话的样子**：会话类型写"作为上网出口"，下面一句"对方的上网流量正从这台电脑出去，只走 TCP，对方看不到你的屏幕"；没有权限区、没有聊天，只有时长和"断开"。上游只把"端口转发：主机:端口"那行换成"作为出口"（`flutter/lib/desktop/pages/server_page.dart:526-535`），其余照普通端口转发处理。不记录访问目标是已定的设计（第四期 C13），所以这里不显示访问了什么。
- **普通端口转发、终端、摄像头会话**：会话类型分别写"端口转发：‹目标主机›:‹端口›"（目标照上游显示）、"终端"、"查看摄像头"。
- **权限区**：每项一个带文字的开关，两列排。远程桌面会话：键盘鼠标、剪贴板、声音、文件复制粘贴、远程重启、录屏、阻止本地输入（Windows）、隐私模式（系统支持时）；摄像头会话只有声音、录屏；文件传输、端口转发、终端、出口会话和已断开时不显示。上游只有图标，名字藏在悬停提示里（`flutter/lib/desktop/pages/server_page.dart:632-665`）。内置选项禁止在这里改权限时整块只读。
- **操作区**

  | 状态 | 按钮 |
  |---|---|
  | 请求中，审批方式含点击 | 接受（主按钮）、拒绝；便携版能提权时多一个"接受并提权" |
  | 请求中，审批方式只用密码 | "对方正在输入密码…" + 拒绝（上游这时只剩一个"取消"，不说明，`flutter/lib/desktop/pages/server_page.dart:1085`） |
  | 已连接 | 断开（危险样式）；便携版可提权时"提权" |
  | 对方发起语音 | 接听、拒绝 |
  | 通话中 | 麦克风选择、挂断；本机没有麦克风时，点麦克风选择提示"没有找到音频输入设备"（上游 no_audio_input_device_tip） |
  | 对方是互换过来的 | 换回来 |
  | 已断开 | 关闭（关的是最后一个时整个窗口关闭） |

- **聊天侧栏**：消息列表、输入框；对方断开后只读。
- **文件记录侧栏**：每条一个动作（发送、接收、删除、新建文件夹、重命名）、文件名、大小、进度或结果；空的时候"还没有文件传输"。纯展示，没有操作。

#### 状态

- 没有来访：窗口不显示；持续 6 秒没有来访就关掉进程（`flutter/lib/models/server_model.dart:165-170`）。
- 新来访：窗口显示并置顶。
- 存了正确密码、直接连进来的来访没有"请求中"这一步，CM 弹出时就是已连接。
- 已授权后收成贴边小条（§8 Q5）。时机沿用上游：密码直接通过的，3 秒后收起（`flutter/lib/models/server_model.dart:581-586`）；点"接受""接受并提权""提权"的，当场收起（上游这两种情况分别是 3 秒后和当场最小化到任务栏）。在完整小窗里按下或移动鼠标会取消这次自动收起。
- **贴边小条**（就是 CM 这个窗口缩成的一条，不是另一个窗口）：
  - 位置：默认贴在主显示器上边、靠右，和完整小窗同一角；可以沿屏幕上边左右拖动，位置记住；置顶。多显示器时出现在主显示器上。
  - 一个连接时的文案按会话类型变："正在被 ‹名字› 远程控制""‹名字› 正在传文件""‹名字› 正在把这台电脑当出口""‹名字› 正在用终端""‹名字› 正在查看摄像头"，后面是时长和"断开"。
  - 几个连接时写"N 个连接正在进行"和"展开"，不放"断开"（要断哪一个，展开后在标签里断）。
  - 点小条空白处或"展开"恢复完整小窗。
  - 远程点击保护（下一条）对小条一样生效：控制方在画面里点"断开"不算数。
- 远程控制者的鼠标点不动 CM（没有"远程修改配置"权限时）：上游用 120 ms 的本地鼠标时间区分本地点击和远程点击（`flutter/lib/desktop/pages/server_page.dart:1237-1248`）。保留；被判定为远程点击时，按钮旁提示"请在这台电脑上操作"。
- 关窗口：连接多于一个时先确认"断开全部连接？"。

#### P3 要画的状态

请求中（含点击 / 只用密码两种）；已连接远程控制（权限区展开）；已连接摄像头（权限只有声音、录屏）；已连接文件传输（文件记录侧栏展开）；普通端口转发（显示目标）；终端；出口会话；聊天侧栏展开；语音来电、通话中、没有麦克风的提示；多个来访标签；贴边小条（一个连接、几个连接各一张）；远程点击被拦下的提示；已断开。

#### 和上游比的变化（P3 汇总）

| 变化 | 理由 |
|---|---|
| 权限加文字 | 只有图标认不出来 |
| 只用密码时说明"对方正在输入密码" | 上游只剩一个"取消"，不知道在等什么 |
| 出口会话专门的样式和说明 | 被控方要知道"出口"不是在看屏幕 |
| 授权后收成贴边小条（Q5） | 最小化后容易忘了有人连着，出口会话一挂几小时 |
| 颜色跟随主题 | 上游写死的渐变在深色模式下也不变 |

### 3.4 P4 手机设备列表

**用途**：手机 App 的首页，找设备、发起连接。

**首屏先看什么**

1. 统一输入框：输 ID 或搜索。
2. "最近"里的设备。
3. 每台设备在不在线。
4. 账号状态（顶栏头像）。

#### 区块

- **顶栏**：左边"Leapgate"；右边账号头像（没登录时是"登录"文字按钮）、设置齿轮。已登录时点头像弹出账号面板：头像、显示名、@用户名，"退出登录"（先确认）。
- **统一输入框**：和桌面同样的规则（§3.1 区块 E）：有输入时列表变成跨分类的搜索结果，最上面一行"连接到 ‹输入的内容›"，右侧带一个看得见的"⋯"。点那一行或键盘回车发起远程桌面连接，点"⋯"弹出连接方式面板（远程桌面、文件传输、终端、摄像头）。上游手机连接页只有一个"→"箭头，新输入的 ID 不在任何列表里时没法直接发起文件传输（`flutter/lib/mobile/pages/connection_page.dart:337-345`）。
- **分类**：最近、收藏、局域网、地址簿、同组设备，带文字，横向可滑。上游竖屏只有图标（`flutter/lib/common/widgets/peer_tab_page.dart:576-656`）。分类条最右端一个"⋯"，里面是排序（名称、ID、用户名、在线状态）、显示哪些分类和分类顺序、地址簿的标签条开关；上游竖屏把这些收在一个"更多"下拉里（同一段代码），手机上不提供卡片 / 列表视图切换（竖屏只有单列，上游也是）。
- **地址簿分类**：分类下方一行"地址簿切换 + 权限文字 + ⋯"，再一行可横滑的标签条。"⋯"里和桌面地址簿的"更多"相同：添加设备、添加标签、取消选择所有标签、与最近会话同步、按交集筛选。上游竖屏把簿选择和整片标签云压在列表上方，权限和所有者只在横屏显示（`flutter/lib/common/widgets/address_book.dart:75-142`）。
- **设备卡片**（单列）：平台图标（和桌面卡片一致）、名称、在线状态、`用户名@主机名`、标签色点、钥匙图标、右侧"⋯"。
- **点卡片**：直接以远程桌面连接，不等双击超时（去掉手机上的双击识别）。
- **长按的含义统一**：长按一个东西 = 弹出这个东西的操作面板。长按卡片 = 卡片的"⋯"；长按标签条里的标签 = 标签的操作（重命名、改颜色、删除，簿可写时）。
- **"⋯"或长按卡片**：底部弹出操作面板：

  | 组 | 项 |
  |---|---|
  | 连接方式 | 远程桌面、文件传输、终端、终端（管理员，对端是 Windows 时）、摄像头（后四个是第二轮页面） |
  | 这台设备 | 始终经中继连接、网络唤醒（局域网） |
  | 整理 | 重命名、收藏、加入地址簿、标签、备注、共享密码、忘记密码、在哪些地址簿里 |
  | 其他 | 多选、删除 |

  上游长按直接进多选（`flutter/lib/models/peer_tab_model.dart:150-157`），长按分类栏又是隐藏的"显示哪些分类"菜单，同一个手势挂了三种含义。新设计长按统一弹操作面板，多选从面板里进。手机上没有 TCP 隧道和出口（§8 Q7）。
- **多选**：顶栏换成多选条（已选 N 台、全选、删除、收藏（最近）、加入地址簿（已登录）、编辑标签（地址簿）、退出）。
- **下拉刷新**：刷新列表和在线状态。
- **链接拉起**：别的 App 里点 Leapgate 的连接链接，直接打开对应的会话（上游手机连接页监听 uni-link，`flutter/lib/mobile/pages/connection_page.dart:55`），行为保留，不画。

#### 状态

加载中；各分类的空状态；没登录（地址簿、同组设备）带登录按钮；网络错误和重试；搜索中（"连接到…"一行、匹配的设备、"正在加载其他分类…"）；搜索无结果（只剩"连接到 ‹输入›"和"没有匹配的设备"）；分类条"⋯"展开；地址簿"⋯"展开；多选；操作面板展开；账号面板展开；登录对话框（可选）。

#### 和上游比的变化（P4 汇总）

| 变化 | 理由 |
|---|---|
| 去掉底部导航，账号和设置放顶栏 | 聊天、共享屏幕是被控端功能，剩两项不值得一条底栏 |
| 去掉更新横幅 | 指向 rustdesk.com/download（`flutter/lib/mobile/pages/connection_page.dart:122-146`） |
| 输入框和搜索合并 | 同桌面 |

| 长按统一弹操作面板 | 上游长按挂了三种含义 |

### 3.5 P5 手机会话页

**用途**：在手机上看和操作远程电脑。一次一个会话（§8 Q8）。

**首屏先看什么**

1. 远程画面（全屏，隐藏系统状态栏和导航栏）。
2. 连接状态。
3. 底部工具条。
4. 键盘（打字时）。

**竖屏和横屏都要能用**：远程桌面通常是横向的，很多人会把手机转过来。样稿两种方向都画。按 Android 的习惯画（Material 风格的面板、系统返回手势），iOS 以后再适配。

#### 区块

- **连接过程面板**：和桌面同样的状态（§3.2 区块 D），居中卡片，底色用主题里的浮层颜色。握手完成前上游用一块和画布同色的遮罩挡住工具条（`flutter/lib/mobile/pages/remote_page.dart:529-544`），新设计里工具条只保留"断开"。
- **工具条**：断开、键盘、输入、画面、更多、连接方式标记、收起。竖屏时在底边；横屏时竖排在右边（底边留给软键盘和辅助键条，横屏高度只有约 390，键盘一弹出就只剩一半）。收起后屏幕角落留一个小按钮，点了再展开。

  | 按钮 | 打开什么 |
  |---|---|
  | 断开 | 确认"断开连接？"；系统返回键也是这个 |
  | 键盘 | 弹出系统软键盘和辅助键条 |
  | 输入 | 输入面板，见下 |
  | 画面 | 画面面板：显示器（多屏时）、缩放（原始、适应、自定义百分比）、画质、编码、光标（显示远程光标、跟随远程光标、跟随窗口焦点）、分辨率（有键盘权限时，二级列表）、虚拟显示器（Windows 对端，二级）。上游手机的显示选项里也有分辨率和虚拟显示器（`flutter/lib/mobile/pages/remote_page.dart:1460-1480`） |
  | 更多 | 更多面板，分三组：操作（Ctrl+Alt+Del、锁定、重启、阻止本地输入、请求提权、系统登录密码、把剪贴板敲进去、重置 Wayland 键盘授权（Wayland 对端）、刷新、重置画布、录屏、备注；安卓对端的返回、主页、最近任务、音量、电源）；会话开关（静音、剪贴板、会话结束后锁定、隐私模式、真彩色）；聊天，以及语音通话（只在 Android 上有，iOS 上游就没有） |
  | 连接方式标记 | 点开连接详情面板（§4.2），质量数据的开关也在里面 |

- **输入面板**的内容有依赖关系（照上游 `flutter/lib/mobile/widgets/gesture_help.dart:39-351`），样稿要按依赖画，不要画成一组同时可见的开关：
  - 最上面是"鼠标模式 / 触控模式"两段切换，下面是当前模式的手势说明。
  - "显示虚拟鼠标"开关两种模式都有。
  - 触控模式下才有"虚拟鼠标大小"滑块。
  - 鼠标模式下才有"显示虚拟摇杆"；摇杆打开后才出现"相对鼠标模式"。
  - 不分模式的几项：只看模式、锁定画布、反转滚轮、左右键互换、交换 Ctrl 和 Command。
  - 对端是安卓时：模式固定为触控并写明原因，没有摇杆，多一个"安卓导航键"开关。

  上游会话功能散在三个入口（电视图标、⋮、鼠标图标），键盘类开关和只看模式放在"显示选项"里（`flutter/lib/common/widgets/toolbar.dart:1202-1217`、`flutter/lib/mobile/pages/remote_page.dart:1342-1349`）；对端是安卓时，"模式"按钮的位置换成扳手，同一个位置功能不同（`flutter/lib/mobile/pages/remote_page.dart:631-643`）。新工具条每个位置的含义固定。
- **手势**：两种模式照上游（`flutter/lib/mobile/widgets/gesture_help.dart:39-351`）。鼠标模式像触控板：单指滑动移光标、单击左键、长按右键、双指点按右键、双击按住拖动、双指平移、捏合缩放、三指上下滚动。触控模式光标跟手指：点哪里点哪里、单指拖动。说明文字要和代码一致：上游帮助里没写"双指点按 = 右键"（`flutter/lib/common/widgets/remote_input.dart:309-323`），而对端是安卓时三指滚动其实被关掉了（`flutter/lib/common/widgets/remote_input.dart:520`）。第一次进入会话时显示一次手势说明（可关），之后在输入面板里能找到。
- **键盘**：辅助键条贴在软键盘正上方（上游贴在画面顶部），内容照上游：Ctrl、Alt、Shift、Win/Cmd 四个粘滞修饰键，Fn（展开 F1~F12），Esc、Tab、Home、End、Ins、Del、PgUp、PgDn、PrtScr 等，方向键，复制、粘贴、保存三个组合键，固定按钮。
- **Wayland 对端**：对端是 Linux Wayland 时，第一次用软键盘或"把剪贴板敲进去"之前，弹一个风险确认（可勾"记住选择"），和桌面一样。"更多"里的"重置 Wayland 键盘授权"用来撤回这个选择。
- **虚拟鼠标**：默认关。触控模式是一只完整的鼠标形状（左右键、滚轮、中键、拖动手柄），7 秒不用缩小；鼠标模式是分开的滚轮条、左右键和可选摇杆。保留，第一轮画一张开启态即可。
- **会话通知**：从顶部安全区下方滑入，一次显示一条，后面的排队；只是告知的几秒后消失。要操作的（截图另存、打印选择、提权）用底部面板。内容和桌面区块 E 相同。
- **质量数据浮层**、**聊天浮窗**：同桌面。

#### 状态

连接过程的各状态（竖屏）；连上后的默认态（竖屏、横屏）；工具条收起；键盘弹出带辅助键条（竖屏、横屏各一张）；输入面板（鼠标模式、触控模式各一张）、画面面板、更多面板各一张；连接详情面板；首次手势说明；虚拟鼠标开启；对端是安卓时的输入面板和导航浮条；Wayland 风险确认；会话通知；断开确认；出错（例如对方离线、自动重试倒计时）。

#### 和上游比的变化（P5 汇总）

| 变化 | 理由 |
|---|---|
| 工具条按"键盘 / 输入 / 画面 / 更多"固定分工 | 上游三个入口分组不对，同一位置随对端变功能 |
| 连接方式常驻工具条 | 上游只在显示选项对话框顶部能看到（`flutter/lib/mobile/pages/remote_page.dart:1282-1285`） |

| 辅助键条贴在键盘上方 | 手指够得着 |

## 4. 跨页面的状态和反馈

### 4.1 连接全过程

| 阶段 | 桌面会话标签（P2） | 手机会话页（P5） | 被控端 CM（P3） | 可能的失败和下一步 |
|---|---|---|---|---|
| 1 发起 | 点"连接"后立刻出现新标签（或切到已有的同设备标签），状态面板"正在连接 ‹设备名›" | 推入会话页，同样的面板 | — | — |
| 2 找到对方 | 进度第 1 步"找到对方"：经 Leapgate 服务器找到这台设备 | 同 | — | ID 不存在；对方不在线（第一次连就不在线时不自动重试）；连不上服务器；密钥不一致 |
| 3 建立连接 | 第 2 步"建立连接"：直连和中继同时尝试，谁先通用谁（自研 ICE 和上游路径竞速，architecture §3.8）。界面不展示竞速细节 | 同 | — | 直连被网络中断（开着代理或 VPN 时常见）→"改用中继"；中继也连不上 → 重试 |
| 3a 不安全 | 通道没有端到端加密时，面板换成警告，等用户选"继续"或"断开"（Rust 侧在这里等待，`src/client/io_loop.rs:219`） | 同 | — | — |
| 4 验证 | 第 3 步"验证"：存过密码的自动登录；否则密码框，提交后"正在验证…"；2FA；等对方接受；多用户会话选择 | 同 | 要输密码或点接受时弹出 CM：请求中，显示接受 / 拒绝或"对方正在输入密码"；存了正确密码直接通过的，CM 弹出时已经是已连接 | 密码不对；验证码不对；对方拒绝；输错太多次被暂时拒绝 |
| 5 等画面 | "已连接，正在等待画面…"；1.5 秒后还没画面时程序会悄悄给对方发一个空的系统登录密码来唤醒锁屏（上游行为，`flutter/lib/models/model.dart:1201`，保留） | 同 | CM：已连接，开始计时 | 对方没有显示器 → 说明并建议虚拟显示器 |
| 6 连上 | 面板消失；标签和工具栏出现"直连 / 经中继"；第一次连上时短暂提示一次"已直连"或"经服务器中继" | 同 | 授权后 CM 收起（Q5） | — |
| 7 会话中 | 对方重启：面板"对方正在重启，重启完会自动重新连接"，最后一帧变暗（上游只是保留最后一帧、静默重连，看起来像卡住了，`flutter/lib/models/model.dart:929-948`）；网络中断：面板"连接断了，2 秒后重试（第 2 次）"，间隔从 1 秒起每次翻倍（1、2、4、8…，没有上限，`flutter/lib/models/model.dart:123`、`:1093-1102`），旁边"立即重试"；这次会话连上过、之后对方掉线（例如对方注销、切换用户）报"对方不在线"时，30 秒内照样自动重试（`flutter/lib/models/model.dart:1002-1010` 要求本次会话已经收到过对方信息） | 同 | CM：对方暂时断开时显示"已断开" | — |
| 8 结束 | 我方断开：标签关闭（标签里还有别的视图时只关这一个视图）；对方断开或超时：面板说明原因，按钮"重新连接""关闭标签" | 我方断开：回到设备列表；对方断开：面板说明原因 | CM：已断开，按钮"关闭" | — |

### 4.2 连接方式指示

**第一级（常驻）**

| 状态 | 文案 | 放在哪 |
|---|---|---|
| 直连 | 直连 | 桌面：会话标签上的小标记、工具栏的连接方式标记；手机：工具条的连接方式标记；出口卡片的状态行 |
| 中继 | 经中继 | 同上 |
| 未加密 | 未加密（警告样式），和直连或中继同时显示 | 同上 |

- 文案说明（悬停或点开时）："直连：两台电脑直接相连，速度取决于两边的网络。""经中继：直连没成功，自动改经 Leapgate 服务器转发，画面可能慢一些。""未加密：这条连接没有端到端加密。"
- CM 不显示连接方式。被控方一般不关心；以后要显示出口会话走没走中继，再补数据。

**第二级（点开的详情）**

- 路径：局域网直连 / 直接 IP 访问 / 打洞直连（IPv4）/ 打洞直连（IPv6）/ 经中继 / 经中继（WebSocket）。打洞不区分是 Leapgate 自研 ICE 还是上游的打洞，用户不需要知道这一层。
- 中继服务器：名字（经中继时）。
- 传输：TCP / UDP（打洞直连可能是 TCP 打洞，也可能是 UDP）。
- 加密：已加密 / 未加密；指纹（两行，可复制，代替上游标签右键里的"复制指纹"）。
- 画面数据：编码、帧率、延迟、目标码率、色度。
- 开关"在画面上常驻显示质量数据"（这是唯一的开关入口，菜单里不再放）。

**现在的数据够不够**：第一级够用：连接就绪时 Rust 推来"是否加密、是否直连、传输类型"三项（`flutter/lib/common/shared_state.dart:110-130`）。第二级不够：Leapgate 自研 ICE 连上时传输类型给 "UDP" 或 "IPv6"，和上游打洞一样（`src/leapgate_hooks.rs:272`）；局域网多候选连上给 "TCP"，和普通直连一样（`src/leapgate_hooks.rs:76`）；经中继时 Rust 给 "Relay"，界面显示时又改写成 "TCP"（`flutter/lib/common.dart:4206`）；而且看不到用的是哪台中继。所以路径字段要由 Rust 直接给出上面那几种取值之一（§8 Q3）。

### 4.3 错误怎么说人话

现在的错误正文是 Rust 给的英文原句，整句或切段翻译，混着系统错误原文（`flutter/lib/common.dart:1353`）；能不能自动重试，靠 Rust 对英文正文做关键字匹配（`src/client.rs:5192`）。新界面按"原因 → 能不能重试 → 下一步"来显示。下表是第一轮要覆盖的，样稿里至少画"对方不在线""直连被中断""密码不对""对方拒绝出口"四种。

"自动重试"一列写的是**现在的行为，新界面不改**：Rust 的判断规则是标题为 "Connection Error"、正文不含 offline、not exist、failed、resolve、mismatch、manually、restricted、incoming only、not allowed 这些词时才自动重试（`src/client.rs:5192-5209`），所以凡是以 "Failed" 开头的都不自动重试，只给"立即重试"按钮。"登录被拒"一类的标题是 "Login Error"，一律不自动重试。

### 4.5 反馈分三层，各管各的范围

1. **连接阶段状态面板**：只在一个会话标签的内容区里，替代模态框链。
2. **会话通知**：只在一个会话标签里，不打断，可以叠多条，后来的不冲掉前面的。
3. **全局轻提示**：例如"已复制"，几秒消失。上游有两套轻提示（`flutter/lib/common.dart:1023` 和 `flutter/lib/models/model.dart:1032`），合成一种。

对话框的范围：会话里的对话框只遮住那个会话标签（上游会话页就是这样做的，`flutter/lib/common/widgets/overlay.dart:618-660`）；主页的对话框只遮主页。单窗口后不能再让一个全局对话框盖住所有标签（上游主窗口、TCP 隧道、出口相关的弹窗挂在窗口全局上）。

## 7. 给设计师的约束和交付要求

### 7.0 两个风格方向的输入

本说明不定颜色、字体和视觉风格，这里只给方向需要的背景：

- 产品是一个人维护、给自己和几个朋友、家人用的远程桌面。最要紧的用户是最不熟悉软件的被帮者：打开主窗口就该看懂"把哪两样告诉对方"、"现在有没有人连着我"。控制方是懂行的人，要的是快、信息不藏、状态说实话。
- 两个方向要在一个主要维度上明显拉开（例如信息密度、整体气质），维度由设计师选，每个方向附一段话说明取向和取舍。两个方向都要满足 §7.1 的全部约束。
- 名字 Leapgate（一跃 + 门，中文名跃门）只作背景，不要求在界面里用门、跳跃这类图形去表现。
- 反面参照是上游现在的界面：写死的渐变色、只有图标没有文字、十几项平铺的菜单。

### 7.1 设计约束

- **深浅色**：两套完整的配色都要，跟随系统，也能手动切。所有颜色从主题来，不写死。上游写死颜色的几处（CM 信息头的蓝色渐变、提示卡的粉紫渐变、工具栏的蓝和红、TCP 隧道的绿条）都要换成主题里的颜色。状态色（在线、离线、连接中、警告、错误、直连、中继）在两套配色里都要分得清，而且不能只靠颜色区分：在线点旁边有文字，中继标记有文字。
- **对比度**：两套配色都按 WCAG AA：正文和小字至少 4.5:1；大字、图标和状态标记至少 3:1。用户自选的标签颜色只用作色点，不承担文字对比度（§3.1 区块 F）。
- **Windows 高 DPI**：按逻辑像素设计，要在 100%、125%、150%、200% 缩放下都清楚。不要依赖 1 像素细线才能看懂的细节；图标用矢量。
- **中英文长度差**：英文的按钮和标签通常比中文宽 1.5~2.5 倍。按钮和标签不要定死宽度；菜单项、卡片名称放不下时省略并在悬停时显示全文；设备名可能很长（例如主机名 DESKTOP-XXXXXXX）。
- **桌面窗口尺寸**：主窗口默认 1280×800，最小 960×600（逻辑像素）。顶栏约 40 高。最小宽度下左栏仍是约 240，右侧约 720 要放得下连接框、分类和列表视图。远程会话的画面区在最小窗口时约 960×560。CM 紧凑态约 300~320×500，展开约 700×500，贴边小条约 320×48（§3.3）。
- **Windows 窗口外观**：自绘标题栏，窗口按钮在右上角，尺寸和顺序符合 Windows 习惯（最小化、最大化 / 还原、关闭，关闭悬停变红）。
- **手机**：竖屏 390×844 为主，另用 360×800 抽查最窄的常见 Android 屏；会话页另画横屏 844×390。先做 Android，按 Android 的习惯画（Material 风格的底部面板、系统返回手势），iOS 以后再适配。注意顶部刘海、底部手势条的安全区。
- **触控目标**：手机上可点的东西不小于 48×48（安卓 dp，iOS 至少 44 pt）；桌面上的可点区域高度不小于 28，常用按钮不小于 32。
- **ID 的显示**：等宽数字，每 3 位空一格。
- **远程画面**：画面区四周的空白用中性色；默认状态下除了浮动工具栏，不要有任何东西压在画面上。样稿里的远程画面画一个虚构的、抽象的桌面（几个简单窗口、占位文字和图标），不用真实的系统或软件截图；远程分辨率按 1920×1080 缩放进画面区。
- **字体**：设计师自定，但要装得进 App：Flutter 会把字体打进安装包，中文字体动辄十几 MB，所以中文用系统字体（Windows 是微软雅黑 UI，Android 是系统自带的中文字体）；西文和数字可以选一款开源许可（例如 OFL）、体积小的字体随包带上，ID 和数字用等宽数字。样稿要发成网页，网页里的外部字体只能从 Google Fonts 加载，所以西文字体请在 Google Fonts 里选。
- **Logo 和图标**：这一轮不设计 Logo、应用图标和托盘图标（现在的应用图标是占位图，等视觉方向选定后另做），顶栏最左画一个 16 像素左右的占位方块。界面里的功能图标由设计师选一套风格统一的矢量图标。
- **示例数据**：用 §7.4 的数据，不要自己编。样稿是公开仓库的一部分，不能出现任何真实的服务器名、域名、IP 和设备 ID。
- **不要画的数据**：设备卡片上的最后在线时间、延迟、能否当出口（§3.1 区块 F）。
- **产品名**：界面里一律写 Leapgate（§8 Q9）。

## 8. 维护者的取舍

### 8.1 起草时提出的九条

维护者 2026-10-28 全部按推荐定（Q10、Q11 同）。每条留下依据、代价和没选的备选，以后回头查。

**Q1 会话标签：一台设备一个标签**，标签里切换远程桌面、文件、终端、摄像头；出口和 TCP 隧道不占标签。

- 依据：上游每种会话各开一个窗口（`flutter/lib/common.dart:2525-2565`），搬进单窗口后，同一台设备会冒出 3~4 个同名标签。从远程桌面打开文件传输本来就复用同一个令牌、不用再输密码（`flutter/lib/common/widgets/toolbar.dart:580-610`）。用户的心智单位是"我在为哪台电脑干活"。
- 代价：一个标签挂几个会话，关标签要一起断（§3.2 区块 G）；标签上的连接方式按"显示最差的那个"处理（§2.1）。
- 实现时要做：按设备 ID 记的共享状态要改成按会话记。现在远程标签和出口在同一个设备 ID 上各自初始化、删除连接类型状态（`flutter/lib/desktop/pages/remote_tab_page.dart:67`、`:382`，`flutter/lib/leapgate/exit_tunnel.dart:30-31`），以前在不同 engine 里互不影响，放进同一个 engine 后关掉一个会删掉另一个的状态。
- 备选：每种会话一个标签，和上游的窗口划分一致。实现简单，但同一台设备会有几个同名标签，关远程桌面时文件传输还开着也看不出来。

**Q2 连接框和设备搜索合并成一个输入框**，最上面一行是"连接到 ‹输入›"，匹配规则统一。

- 依据：上游两处的匹配规则不一致（`flutter/lib/desktop/pages/connection_page.dart:393-404`、`flutter/lib/common.dart:1680-1700`），连接框的下拉本来就在搜设备，再加一个搜索框是重复。
- 细化（§3.1 区块 E）：回车默认执行哪一行看输入像不像地址，按名字搜索时默认选第一台匹配的设备，不会拿名字当 ID 去连；不再预填上次的 ID，也去掉每次连接时把 ID 写回输入框（`flutter/lib/common.dart:2584-2594`）。
- 备选：和上游一样分开，连接框只管输 ID，设备列表另有搜索框；两处的匹配规则统一成一套。

**Q3 连接方式分两级**：第一级只显示"直连 / 经中继 / 未加密"，用现有数据；第二级详情里显示路径（局域网直连、直接 IP 访问、打洞 IPv4 / IPv6、经中继、经 WebSocket 中继）和用的是哪台中继，为此让 Rust 在连接就绪事件里多给一个路径字段和中继名。

- 依据：现在的传输类型分不出自研 ICE 和上游打洞、局域网多候选和普通直连（`src/leapgate_hooks.rs:76`、`:272`），中继在界面上又被写成 "TCP"（`flutter/lib/common.dart:4206`），智能选中继选了哪台也看不到。排障时这些信息最有用，Leapgate 的直连和选路改进也只有这样才看得出效果。
- 代价：多一处 Rust 改动和一个新的导出（放 `src/leapgate_ffi.rs`）。
- 备选：只做第一级（直连 / 经中继 / 未加密），不改 Rust；排障时看日志。

**Q4 出口在主页单独一页**：目录、正在使用、按 ID 使用三块；点"使用"后自动建本地代理，出口在后台运行、不占会话标签，主页标签和导航上显示在用数量；设备菜单和连接按钮下拉里加"用作出口"（只对 Windows 对端）。

- 依据：现在至少 6 步，而且 TCP 隧道窗口必须一直开着（§1 S3）。单窗口后隧道活在主窗口进程里，不再需要一个可见的窗口托着它。出口是 Leapgate 的特色功能，藏在"…"菜单最后一项不合适（`flutter/lib/desktop/pages/connection_page.dart:583-588`）。
- 代价：要改第四期 F1"复用 TCP 隧道窗口"的做法。F1 是为了过渡期少改上游 Dart 文件（F7），新界面重写后不受这个限制。
- 细化（§3.1 区块 I）：端口按设备记，第一个 21180，之后自动取下一个没被别的出口卡片用的建议值；被别的程序占着时照第四期 A10 不自动换，提示改端口。一台设备最多一张卡片。重启程序后不自动恢复。
- 备选：保持第四期的做法，出口目录留在连接按钮的菜单里，"使用"后打开 TCP 隧道视图、在那里加出口；改动小，但步骤多、要一直开着那个视图。

**Q5 CM 授权后收成贴边小条**："正在被 ‹名字› 远程控制 · 00:12:34 · 断开"，点开恢复完整小窗。

- 依据：上游授权后最小化到任务栏（密码直接通过的 3 秒后，`flutter/lib/models/server_model.dart:581-586`；点接受类按钮的当场，`flutter/lib/desktop/pages/server_page.dart:1031`、`:1094`、`:1117`），被控方很容易不知道有人连着；出口会话一挂就是几个小时，最小化以后只剩任务栏一个图标。小条足够小，不太挡控制方的视野（控制方看到的是被控端整个屏幕，CM 也在里面）。
- 代价：多一种窗口形态要实现；控制方在画面里也会看到这条。
- 细化（§3.3）：小条的位置、按会话类型变化的文案、几个连接时的写法、远程点击保护照样生效。
- 备选：照上游，授权后最小化到任务栏；或者授权后保持完整小窗不收起。

**Q6 便携版点关闭窗口时先问一句**："退出 Leapgate（别人就连不进来了）"或"留在后台"，可以勾选记住；安装版照旧隐藏到托盘。两种版本都是：有远程会话开着时先确认断开。

- 依据：便携版的被控服务跑在主窗口进程里（`src/core_main.rs:218`），托盘只在安装版服务运行时才有（`src/tray.rs:70-71`）。现在关窗只是隐藏（`flutter/lib/desktop/widgets/tabbar_widget.dart:442`），进程还在、还能被连。再运行一次程序能把隐藏的窗口找回来（`flutter/windows/runner/main.cpp:93-122`），但界面上没有任何地方说，用户多半以为程序已经退出，也不知道自己还能被连。单窗口后主窗口还托着所有会话和出口。
- 细化："留在后台"那一项下面写一行"被控服务和在用的出口会继续运行；再次打开 Leapgate 就能找回窗口"。
- 备选：便携版点关闭就直接退出（别人连不进来了，出口也停）；或者照旧隐藏，只在第一次隐藏时提示一次"Leapgate 还在后台运行"。

**Q7 手机第一版不做出口**：手机上没有出口页，设备操作面板里没有"用作出口"和 TCP 隧道。

- 依据：手机上的连接入口不处理 TCP 隧道（`flutter/lib/common.dart:2629-2719`），出口的本地代理只编在桌面（`src/leapgate_hooks/exit.rs` 里的代理部分都排除了 Android 和 iOS，只有取目录的挂钩不排除）。手机上真要让别的 App 走出口，要么做本机代理（只有能设代理的 App 有用），要么做 VPN 服务，而 architecture §3.9 已定不做自研 VPN，Android 同时也只能有一个 VPN。
- 备选：手机上也做本机代理，只对能手动设代理的 App 有用，要把代理部分编进移动端。

**Q8 手机一次一个会话**。会话开着时再点另一台设备，提示"先断开 ‹当前设备›？"。

- 依据：上游全局只有一个会话对象，会话页关掉时直接关闭连接（`flutter/lib/mobile/pages/remote_page.dart:184-221`）；手机上临时连一下是主要场景。
- 备选：手机也能同时开几个会话、在会话页里切换，要改上游"全局只有一个会话对象"的结构。

**Q9 界面里一律写 Leapgate**（标题栏、托盘、服务状态、提示文案），中文名"跃门"只出现在关于页和说明文档里。

- 依据：界面里的应用名来自运行时的 APP_NAME，上游译文里的 "RustDesk" 是运行时替换成应用名的（architecture §3.10），中英文用同一个名字就不用多维护一套；APP_NAME 还决定服务名、配置目录，不能按界面语言变。
- 备选：中文界面写"跃门"、英文界面写 Leapgate。APP_NAME 不变，界面另做一层按语言换名字的替换。

### 8.2 修订时提出的两条

按核对意见修订时发现的两条，维护者 2026-10-28 按推荐定。

**Q10 出口第一次登录对方放在什么时候**

- **推荐**：点"使用"时就登录（要密码、等对方接受都在出口页上当场完成）；之后断线照第四期 C9，由下一条本地连接触发重连。
  - 依据：现在出口隧道要等第一条本地连接进来才登录（`src/leapgate_hooks/exit.rs:43-44`，第四期 C5、C9）。照现在的做法，密码框会在用户已经切到浏览器、第一次上网时才冒出来，出口页不在眼前，用户只看到网页打不开。点"使用"的那一刻人就在出口页上，这时问密码最自然。
  - 代价：要改 Rust（第一次建隧道不再等本地连接，契约 C9 的"懒建立"只保留给重连）；对方的 CM 会在点"使用"时就出现一条出口会话，哪怕还没开始上网。
- **备选**：保持懒登录。卡片在"使用"后显示"就绪：有程序第一次走代理时连接对方"；之后要密码或等对方接受时，卡片进入相应状态，主页标签和导航"出口"加提醒标记，用户自己回出口页处理。不改 Rust，但第一次用时多半要来回切一趟。

**Q11 多显示器的两项随单窗口去掉**

- **推荐**：去掉"各显示器独立窗口"和"用上我所有的显示器"，等 Flutter 官方多窗口 API 转正后和"会话拖成独立窗口"一起加回来。
  - 依据：两项都要再开窗口（`flutter/lib/common.dart:3421-3440`、`flutter/lib/common/widgets/toolbar.dart:1169-1182`），单个 engine 的主窗口做不到；第②条已定会话暂不能拖成独立窗口，这两项是同一类。
  - 代价：多显示器用户失去"把远程几块屏摊到本机几块屏上"的用法，只能在一个标签里切屏或合并显示。
- **备选**：把这两项做成多窗口特例，单独为它们开额外的 engine。这会把 flutter#155685 那类多 engine 崩溃、分叉维护的多窗口插件这些包袱带回来（architecture §3.4），不推荐。
