方向 B「控台」

Leapgate 新界面 · 第一轮样稿 · 高密度

取向。B 写给控制方：每天开着它、同时管着好几台设备、连到谁那里是直连还是中继都想一眼知道。所以 B 把“真实状态”放在最显眼的位置：标签里画整条连接路径，设备列表是一张所有字段并排的表，工具栏的每个菜单都有图标加文字。界面本身几乎不上色：灰阶加一个钴蓝，颜色留给状态，这样黄的、红的、绿的出现时就是真的有事。

取舍。字小（正文 13）、行紧（32）、形状几乎是方的，被帮的人会觉得这是别人的工具；ID 虽然仍在左上角，但只有 22 号，不如 A 醒目。换来的是：一屏能看约 20 行设备和每台的全部字段，工具栏和菜单在 960 宽里都放得下，状态变化不需要翻页。

圆角 0 / 2 / 3 / 4 / 6，面性图标 16 格
专属细节
路径标记：两个端点加一条线，经中继时中间多一个菱形，永远带文字

  • “浅色”画框永远是浅色界面，“深色”永远是深色界面，和你正在用的页面主题无关。
  • 画框是固定像素尺寸，宽的在框内左右滚动；1920×1080 那两张默认 1:1，可用画框上方的按钮缩小。
  • 顶部轨道在两套主题里都是深色，路径标记和轨道上的状态色因此取深色那一列；P5 的浅色和深色两张因此几乎一样，只有画面四周的底色不同。
  • P1 的第一行同时画了选中态和悬停态（左边强调条，行尾出现 32 高的“连接”和“⋯”），用来看这两种状态；输入框是空的，所以“连接”按钮是灰的。
  • “最近”按时间排列，所以工具里只有“视图”和“多选”，没有“排序”。表格里也没有“备注”列：说明 §3.1 F 只在地址簿和同组设备里显示备注，§7.4 却给“工作室绘图电脑”写了备注，这里按 §3.1 F 不画，备注列留到第二步的地址簿和同组设备。
  • P2 画的是最大化后的主窗口：窗口按钮中间是“还原”，画框没有圆角。远程画面是虚构的抽象桌面；工具栏没有“显示器”按钮，因为这台对端只有一块屏。
  • P2 的“画面”菜单里画质选了“自定义”，画质（10 到 100）和帧率（5 到 120）两个滑块直接出现在菜单里；缩放没选“自定义”，缩放滑块和“滚动方式”留到第二步。
  • P2 连接过程画的是“要密码”：此刻在等人输入，第 3 步“验证”用静态的实心序号标记，转圈留给“正在验证…”。
  • P3 是请求中，还没有授权，所以没有聊天和文件记录入口；它们在已授权后出现在信息头右上角（第二步画）。
  • P5 是沉浸模式（系统栏隐藏）：左侧的黑点示意前置摄像头开孔，画面让出约 28 的侧边安全区；右侧轨道上下各留 16，“断开”不贴着圆角和底部手势区。轨道把“断开”放在最下面、和其他按钮隔开，避免误触；连接方式标记在最上面，竖着画。
