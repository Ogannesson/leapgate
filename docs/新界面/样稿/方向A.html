方向 A · 低密度

像坐在对方身边一句一句讲清楚。一屏只讲一件事，字大、目标大、字段少，先照顾最不熟悉软件的被帮者。

取向。说明里最要紧的用户是家人：他们打开 Leapgate 只想知道“把什么告诉对方”。当面把这件事做成界面里唯一大而醒目的东西：左栏白色面板上，ID 和密码是全屏最大、最粗的字，周围留白多，没有别的东西抢它。其余部分都安静：雾青灰的底，靠底色深浅而不是描边分层，字号和按钮比常规大一档，一屏只放每台设备的主要信息。

取舍。同一屏能看到的设备少（约 12 台），懂行的控制方会觉得空；“画面”这种二三十项的长菜单在最小窗口里一定要滚动。换来的是：不熟悉软件的人不容易点错，也不容易漏看状态，手机上同一套尺寸直接能用。

字体与字号

字体

西文和数字用 Atkinson Hyperlegible Next（Google Fonts，OFL，400 / 600 / 700 三档，随包带上）。它把 1 和 l、0 和 O 这类容易混的字符画得很不一样，而密码正是 a1b2c3 这种要在电话里念给对方的串。

中文用系统字体，不进安装包：微软雅黑 UI，其次 PingFang SC、Noto Sans SC。雅黑 UI 没有半粗档，中文的强调一律用粗体。数字全部打开等宽（tnum）：ID、密码、时长、码率、延迟。

字号阶梯（字号 / 行高）

ID 的三段读法

九个数字按 3 位成组，组间留 10，每组下一条 4 高、强描边色的短横线。念一组、停一下，听的人按组记。只有左栏本机区的 ID 带横线；卡片、CM 里的 ID 只有组间距。密码紧挨着、同号同粗细、用强调色，不分组。
