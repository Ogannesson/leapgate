配色（2026-10-29 选定）。维护者看过A-配色调整（https://claude.ai/code/artifact/0b642475-a961-41c1-829d-c896da38d56f）的四档后定：整体用“适度”，P1 左栏（本机区、服务状态、被控提示、导航）用“微调”的做法。“适度”做了六件事：设备按 ID 分到七种身份色之一，用在平台图标块、会话标签顶条和被控端小窗里来访者的头像；标签从色点改成带浅底的小块；分类选中项和展开着的菜单按钮换更明确的强调色底；被控端小窗的信息头用固定的浅青底；状态色比第二步初版略饱和；窗口底略偏青。左栏不分色块：本机区仍是白色面板上的 ID 和密码，导航选中项是浅青底，ID 下的三条横线是强调色，“正在被远程控制”仍是灰底。更大胆那一档的梅紫和深青本机区没有采用。用色规则见说明 §2.4、§8.3 Q14。

共用块的用法

本文件的 <style> 里，用“A-基础 共用 CSS 开始 / 结束”两行注释夹住的一段，和正文开头用“A-基础 图标开始 / 结束”夹住的那个 <svg>，是页面文件要原样复制的两块。其余样式只属于本页。

要画什么怎么写
画框<div class="frame win lg-light" style="width:1280px;height:800px" role="group" aria-label="…">
类型：win（桌面主窗口）、cm（CM 小窗）、phone（手机）。主题：lg-light 或 lg-dark。详细模式在后面再叠 lg-detail。
图标<svg class="ic" width="20" height="20" aria-hidden="true"><use href="#i-copy"/></svg>
尺寸写在 width / height 上，线宽按尺寸自动补成显示 2 像素（支持 14、16、18、20、22、24、28、32）。颜色是 currentColor。
连接方式标记（简洁）<span class="stt c-relay"><svg class="mk" width="12" height="12" aria-hidden="true"><use href="#m-half"/></svg><span>经中继</span></span>
直连 m-dot + c-direct；经中继 m-half + c-relay；未加密 m-tri + c-unencrypted；正在连接… m-spin + c-connecting（svg 上再加 spin）。
连接方式标记（详细）<span class="stt p c-relay"><svg class="mk" width="36" height="12" aria-hidden="true"><use href="#p-relay"/></svg><span>经中继</span></span>
直连 p-direct、经中继 p-relay；叠加未加密时换成 p-direct-u、p-relay-u，后面再跟一个 m-tri 的“未加密”。stt 后加 p（间距 8）。
远程画面<svg class="rd" style="left:0;top:0" width="1920" height="1080" viewBox="0 0 1920 1080" preserveAspectRatio="xMidYMid slice" role="img" aria-label="远程设备的桌面（虚构示意）"><use href="#rd-desk" width="1920" height="1080"/></svg>
外层 svg 按画面区尺寸写 width / height，viewBox 固定 1920×1080；手机里要裁切时用 slice。
1920×1080 大画框<div class="sh-fit"><input type="checkbox" id="x"><label for="x">缩小到 50% 显示（默认 1:1）</label><div class="sh-scroll"><div class="sh-box1920"><div class="frame win lg-light" style="width:1920px;height:1080px">…</div></div></div></div>
缩放由 CSS 完成，不需要脚本；页面本身不横向滚动，大画框在 .sh-scroll 里横向滚动。
窗口按钮<svg width="10" height="10" aria-hidden="true"><use href="#w-min"/></svg>
w-min、w-max、w-restore、w-close，放在 .winctl 的 46×40 方块里；关闭悬停的方块加 hot，底读 --lg-winclose（#C42B1C）、字读 --lg-on-winclose（白）。红色关闭按钮是 Windows 的习惯，macOS 和手机不用，所以单独做成令牌，不借用错误色；两套配色取值相同。
尺寸、字号、颜色、间距、圆角height:var(--lg-h-btn);font-size:var(--lg-fs);line-height:var(--lg-lh);background:var(--lg-surface);padding:var(--lg-sp-4);border-radius:var(--lg-r-16)
组件类已经读这些变量，所以详细模式只靠 .lg-detail 换变量；自己写新组件时也取变量，不写死数字和色值。画框里不用 --page-*，页面外壳不用 --lg-*。
输入框聚焦态类名约定之一<div class="field foc">…</div>
聚焦态一律写 .field.foc，不写 .field.focus：共用块里的 .frame .focus 是键盘焦点环（2 像素外描边），任何带 .focus 的元素都会被它套上，输入框再叫 focus 就会多出一圈外描边。共用块已提供下面这一条，页面不用再写：
.frame .field.foc{box-shadow:inset 0 0 0 2px var(--lg-accent)}
.foc 和 .focus 是两个不同的类名，.frame .focus 的外描边套不到 .foc 上，所以输入框只有一圈内描边，不会叠成双环。共用块里原有的 .field.focus 不改名、不删，但新页面不用它。
卡片视图的列数.frame .grid{grid-template-columns:repeat(auto-fill,minmax(300px,1fr))}
共用块已提供，页面不用再写（A-P1里原来自己覆盖的那一行可以删掉；网址 https://claude.ai/code/artifact/76a8eaa6-b51f-41b9-9f7a-e946f6e832a3）。列数自动，每列至少 300（说明 §3.1 区块 F）：1280 宽的窗口内容区约 1008，是 3 列；960 宽的窗口约 688，是 2 列；本页 1000 宽的小样内容区约 968，也是 3 列。
菜单行右侧小字类名约定之二<div class="mr"><span>自定义</span><span class="hint">5%~1000%</span></div>
.hint 只用在菜单行（.mr）右侧，靠 margin-left:auto 推到行尾，共用块里的规则是 .frame .mr .hint。其他组件不再起 .hint 这个类名：页面里别处的 .hint 会和它互相覆盖。例如 P1 的本机提示卡叫 .pcard。
菜单行悬停与危险操作行共用块已提供<div class="mr hv">…</div>　<div class="mr dng hv">…</div>
.hv 是悬停态，底用 --lg-hover；.dng 是危险操作（错误色文字），它悬停时（.dng.hv）底换成 --lg-error-bg，不用 --lg-hover：底色发红，比灰色的悬停更容易认出是危险操作；错误色压在错误底上浅色 4.82、深色 7.58（见对比度）。同一个菜单里只放一项危险操作（说明 §3.1 区块 F）。页面里不要再自己写 .mr.hv、.mr.dng 的底色和字色。
连接管理小窗（CM）信息头详细模式尺寸<div class="cm-head"><span class="av l">李</span><div><div class="nm">…</div>…</div></div>
信息头高、头像、名字字号、间距读 --lg-h-cmhead、--lg-cm-av、--lg-fs-cmname、--lg-lh-cmname、--lg-gap-cmhead（简洁 112 / 52 / 20 / 28 / 16，详细 84 / 40 / 14 / 20 / 12）。页面里不要再为详细模式单独写这几个尺寸。信息头整块是固定的浅青功能底（--lg-cmband），伸到小窗面板的边缘，下面多留 8 像素；头像取来访者的身份实色，字母固定 20 粗（--lg-fs-cmav，两种模式相同）。
身份色（设备、来访者）共用块已提供<div class="card" data-k="6">…</div>　<div class="tr" data-k="6">…</div>　<span class="tab" data-k="6">…</span>
data-k 取 1 到 7，写在卡片、手机卡片、列表行、出口目录卡片、会话标签上；后代自动得到三个变量：--is（实色）、--it（浅底）、--ii（深字）。共用块里已经有规则：卡片和手机卡片里的 .tile 变成身份浅底加身份深字，列表行里的 .pf 取身份深字，没写 data-k 的保持灰块灰图标。取色的函数（哈希）由开发定，同一个 ID 永远同色；示例数据的指派见“身份色”一节，同一台设备在五个页面里同色。文字永远用正文色，身份色不承担文字对比度。被控端小窗：.frame 上写当前选中的来访者的 data-k（头像取实色），标签栏里每个标签各写自己的来访者的 data-k。本机、“正在被远程控制”、输入框里的 ID 都不写 data-k。
会话标签顶条共用块已提供<span class="tab sel">主页</span>　<span class="tab" data-k="6">书房台式机</span>
标签顶部有一条 --lg-strip 厚（3 像素）的色条：写了 data-k 的标签用身份实色，选中的主页标签（没有 data-k）用强调色，被控端小窗里的标签也有。没选中、没写 data-k 的标签没有色条。选中且没写 data-k 的标签（主页标签、被控端侧栏的标题标签“聊天”“文件记录”）顶条一律是强调色，不取来访者的身份色，哪怕所在的 .frame 写了 data-k；只有小窗顶部 .cm-tabs 里的来访者标签才取 --is。规则写在 .tab::before 上，.tab 自己已经是 position:relative，页面不用再写。
标签小块共用块已提供<span class="tg" style="--c:var(--lg-tag-home)"><i></i>家里</span>
8×8 色点加标签色浅底的小块；浅底是 --c 按 --lg-tag-mix（浅色 12%，深色 16%）掺进所在的底（color-mix），标签名用正文色 --lg-text。标签色是用户自选的，所以不为每个标签配浅底令牌，只给 --c 一个值，任意颜色都达标（见对比度）。样稿里 --c 取 --lg-tag-*，那只是示例色。
选中态和位置色共用块已提供<div class="navi sel">…</div>　<span class="cat sel">…</span>　<span class="ti on">…</span>
导航选中项读 --lg-nav（底）和 --lg-navfg（字）：浅青底，P1 左栏用“微调”的取值；分类选中项读 --lg-cat 和 --lg-catfg（桌面分类栏、手机分类条）；工具栏里展开着的菜单按钮读 --lg-active（强调色的 16% / 14%）；ID 三段下面的横线读 --lg-bar（强调色）。页面里不要再自己写这些选中态的底色。

身份色

每台设备、每位来访者按 ID 取一个固定颜色，同一个身份到哪里都同色，用在设备卡片和列表行的平台图标块、会话标签顶部的色条、被控端小窗里来访者的头像上。七种颜色避开状态色：绿色留给在线和直连，红色留给出错，琥珀留给警告，靛蓝留给经中继，青色是强调色，这几个位置身份色一个也不占。色相落在它们之间的空档里，明度上也错开：浅色里身份实色比状态色亮一档，深色里比状态色暗一档。身份色只帮人一眼认出是哪台，设备多于七台时必然撞色，所以不当唯一标识：设备名永远写在旁边，文字不用身份色，对比度不靠它。取色的函数（哈希）由开发定，同一个 ID 永远同色。

每种颜色三个值：实色（--lg-kN-s）用在顶条和头像，上面放 --lg-on-k；浅底（-t）用在设备图标块，上面放深字；深字（-i）是浅底上的图标和列表行里的平台图标。元素上写 data-k="1" 到 "7"，后代用 --is、--it、--ii。
